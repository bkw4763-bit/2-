# 석유 최고가격제 효과 추정: KDI 표 1과 비교

오피넷 일간 자료와 단순 회귀식으로 "최고가격제가 없었다면 주유소 가격이 얼마였을까"를 추정한 코드와 자료입니다. 결과는 KDI 「석유 최고가격제와 유류세 인하의 효과」(중동 전쟁 대응 T/F 긴급 현안자료, 2026.4.22)의 〈표 1〉 "3월 4주 차 최고가격제 효과 추정"과 비교합니다.

## 1. 결과 요약

2026년 3월 22~26일 평균(KDI 표 1의 3월 4주 차, 1차 최고가격이 적용된 마지막 주), 단위는 원/리터입니다.

| 구분 | 휘발유 | 자동차용 경유 | 실내 등유 |
|---|---|---|---|
| 실제: 추정 / KDI | 1,819 / 1,819 | 1,816 / 1,816 | 1,509 / 1,509 |
| 가상: 추정 / KDI | 2,347 / 2,279 | 2,664 / 2,732 | 1,986 / 2,061 |
| 효과: 추정 / KDI | −528 / −460 | −848 / −916 | −477 / −552 |

- 실제 가격은 KDI 표와 일치합니다. 오피넷 주간 평균 판매가격은 일요일~목요일 5일 평균이어서, 3월 4주 차는 3/22~3/26의 평균입니다.
- 가상 가격은 KDI 값과 휘발유 +3.0%, 경유 −2.5%, 등유 −3.6% 차이가 납니다.
- 회귀식의 설정은 KDI 표에 맞추지 않고, 시행 이전 자료만으로 예측이 얼마나 맞는지 검증해 정했습니다(4절).

## 2. 분석의 생각

최고가격제의 효과를 알려면 "최고가격제가 없었다면 주유소 가격이 얼마였을까"를 알아야 합니다. 이 가격은 관측되지 않으므로 다음 순서로 추정합니다.

1. 최고가격제 시행 **이전** 자료로 "국제 제품가격이 주유소 판매가격에 반영되는 관계"를 회귀식으로 추정합니다.
2. 시행 **이후** 날짜에 실제 국제 제품가격을 이 식에 넣어, 평소 관계가 그대로 유지됐다면 형성됐을 **가상 가격**을 예측합니다.
3. **실제 가격 − 가상 가격**을 최고가격제의 효과로 봅니다. 음수이면 그만큼 가격이 낮아졌다는 뜻입니다.

## 3. 사용한 자료

모두 오피넷(한국석유공사 유가정보시스템, www.opinet.co.kr)에서 내려받은 일간 자료이며, 기간은 2015년 1월 1일 ~ 2026년 10월 8일입니다. 원본은 `input` 폴더에 그대로 두었습니다.

| 파일 (`input`) | 오피넷 메뉴 | 내용 | 쓰임 |
|---|---|---|---|
| `retail_daily.csv` | 국내유가통계 > 주유소 > 평균판매가격 (일간) | 보통휘발유·자동차용경유·실내등유 전국 평균 판매가격 (원/리터) | 종속변수, 실제 가격 |
| `intl_daily_krw.csv` | 유가관련정보 > 국제유가 > 석유제품 (일간, 단위 원) | 휘발유(92RON)·경유(0.001%)·등유의 싱가포르 거래가격 (원/리터) | 설명변수 |
| `tax_gasoline.xls`, `tax_diesel.xls` | 유가관련정보 > 유류세 > 세금변동추이 | 변동일자별 유류세 합계 (원/리터, 부가세 제외) | 통제변수 |

`build_dataset.py`가 이 파일들을 합쳐 `data/opinet_daily.csv`를 만듭니다. 이때 두 가지 처리를 합니다.

- **국제가격:** 영업일에만 값이 있으므로 주말과 휴일에는 직전 영업일 값을 씁니다.
- **유류세:** 세금변동추이는 변동일자만 있으므로, 날짜마다 그날 적용된 세액을 붙입니다. 등유는 표본 기간에 세율 변동이 없어 넣지 않습니다.

국제 제품가격은 오피넷이 그날의 원/달러 매매기준율로 환산해 제공하는 원/리터 값을 그대로 씁니다. 따라서 환율 변동이 이미 반영돼 있고 환율 자료는 따로 필요하지 않습니다.

일간 자료를 쓰는 이유는 시점이 정확히 맞기 때문입니다. 최고가격제 시행일(3/13, 금요일)과 유류세 변경일(3/27)을 날짜 단위로 구분할 수 있습니다. 오피넷 주간 자료는 판매가격이 일~목 평균, 국제가격이 월~금 평균이어서 두 값의 요일이 서로 어긋납니다.

## 4. 회귀식과 설정

유종별로 다음 식을 최소자승법(OLS)으로 추정합니다. t는 날짜입니다.

```
판매가격(t) = a + b0·국제가격(t) + b1·국제가격(t−7) + b2·국제가격(t−14) + c·유류세(t) + 오차(t)
가상 가격(t) = 회귀식의 예측값(t) + 시행 직전 7일의 평균 잔차
```

| 설정 | 값 | 이유 |
|---|---|---|
| 자료 주기 | 일간 | 시행일과 세율 변경일을 날짜 단위로 구분 |
| 변수 형태 | 수준(원/리터) | 유류세가 리터당 정액이라 원 단위 전달이 자연스러움 |
| 시차 모형 | 당일만 / 7일 전까지 / 14일 전까지 (모형 3개) | 국제가격이 반영되는 시차를 달리 가정한 모형을 비교하기 위해 |
| 추정 표본 | 2021년 11월 12일 ~ 2026년 3월 12일 (1,582일) | 시작: 유류세 인하 시행일. 끝: 최고가격제 시행 전날 |
| 잔차 보정 | 시행 직전 7일(3/6~3/12)의 평균 잔차를 예측값에 더함 | 검증에서 예측 오차가 절반 이하로 줄어듦 |
| 대표값 | 세 모형 가상 가격의 중윗값 | 한 모형에 기대지 않기 위해. KDI 표 1도 모형별 추정치의 중윗값 기준 |

- **시차를 넣는 이유:** 주유소는 국제가격을 즉시 반영하지 않고 1~2주에 걸쳐 반영합니다. 시차를 며칠로 보느냐에 따라 급등기의 가상 가격이 달라지므로, 세 모형의 중윗값을 씁니다.
- **유류세를 넣는 이유:** 표본 기간에 유류세 인하율이 여러 번 바뀌었고, 2026년 3월 27일에도 인하 폭이 커졌습니다. 유류세를 식에 넣으면 가상 가격에는 실제 유류세 경로가 그대로 반영되고, 최고가격제만 없는 상황을 가정하게 됩니다.
- **잔차 보정을 하는 이유:** 회귀식의 예측값은 실제 가격과 한동안 같은 방향으로 벌어져 있는 경우가 많습니다. 시행 직전에 벌어져 있던 만큼을 더해 주면, 가상 가격이 시행 직전의 실제 가격 수준에서 출발합니다.

**설정을 정한 근거: 가상 시행일 검증**

상한제가 없던 날을 시행일인 것처럼 놓고, 그 전날까지의 자료로 추정한 뒤 9~13일 뒤 5일 평균을 예측해 실제 가격과 비교했습니다. 상한제가 없던 때이므로 차이는 0이어야 하고, 0에서 벗어난 만큼이 이 방법의 예측 오차입니다. `--validate` 옵션으로 다시 계산할 수 있습니다.

| 구간 | 설정 | 휘발유 | 자동차용 경유 | 실내 등유 |
|---|---|---|---|---|
| 평상시 41개 시점 (2023.1~2026.1, 4주 간격) | 본 설정 | 21 (+1) | 26 (+1) | 25 (+1) |
| | 잔차 보정 없음 | 53 (+12) | 58 (+31) | 53 (−12) |
| | 시차 28일 전까지 5개 | 17 (−1) | 21 (+1) | 20 (0) |
| 2022년 급등·급락기 10개 시점 | 본 설정 | 75 (−42) | 100 (−53) | 80 (−56) |
| | 잔차 보정 없음 | 114 (−93) | 103 (−74) | 184 (−171) |
| | 시차 28일 전까지 5개 | 88 (−52) | 120 (−61) | 90 (−66) |

값은 예측 오차의 크기(RMSE, 원/리터)이고, 괄호 안은 평균 오차(가상 − 실제)입니다. 2022년 검증은 그 전 자료가 충분하도록 표본을 2019년 1월부터 잡았습니다.

- **잔차 보정:** 넣으면 평상시 오차가 50원대에서 20원대로 줄고, 한쪽으로 치우친 오차도 없어집니다. 급등기에도 오차가 줄어듭니다.
- **시차 길이:** 28일 전까지 늘리면 평상시 오차는 조금 더 줄지만 급등기 오차가 커집니다. 추정 대상인 2026년 3월이 급등기이므로 14일 전까지만 넣었습니다.
- **오차와 효과의 크기:** 평상시 오차(21~26원)는 추정한 효과(477~848원)보다 훨씬 작습니다.
- **급등기의 한계:** 가격이 급변하던 2022년에는 오차가 75~100원으로 커지고, 평균적으로 실제보다 낮게 예측했습니다. 2026년 3월도 급등기이므로, 가상 가격이 실제보다 낮게 잡혀 효과가 작게 추정됐을 가능성이 있습니다.

## 5. 추정 결과 읽는 법

`output/model_stats.csv`에 저장됩니다.

| 유종 | 모형 | 국제가격 계수 합 | 유류세 계수 | 조정 R² | 잔차 보정(원) |
|---|---|---|---|---|---|
| 휘발유 | 당일 / 7일 전까지 / 14일 전까지 | 0.91 / 1.04 / 1.13 | 0.49 / 0.70 / 0.82 | 0.66 / 0.76 / 0.82 | −162 / +35 / +91 |
| 자동차용 경유 | 당일 / 7일 전까지 / 14일 전까지 | 0.88 / 1.00 / 1.05 | 0.49 / 0.79 / 0.95 | 0.77 / 0.86 / 0.91 | −325 / −22 / +94 |
| 실내 등유 | 당일 / 7일 전까지 / 14일 전까지 | 0.58 / 0.68 / 0.75 | 없음 | 0.53 / 0.65 / 0.73 | −227 / −110 / +108 |

- **국제가격 계수 합:** 국제 제품가격이 리터당 1원 오르면 판매가격이 장기적으로 몇 원 오르는지입니다. 휘발유와 경유는 약 1원으로, 국제가격 변동이 거의 그대로 전달됩니다. 등유는 0.6~0.75원으로 전달이 약합니다.
- **조정 R²:** 시차를 늘릴수록 높아집니다. 당일 가격만 넣은 모형은 가격의 늦은 반응을 담지 못해 설명력이 낮습니다.
- **유류세 계수:** 세금 전달률로 해석하지 마세요. 이 식에서는 가상 가격이 세율 변화에 끌려가지 않게 하는 통제변수일 뿐입니다.
- **잔차 보정:** 시행 직전 7일 동안 실제 가격이 회귀식 예측보다 평균 몇 원 높았는지(+) 낮았는지(−)입니다. 당일 모형의 값이 크게 음수인 것은, 3월 초 국제가격이 급등했는데 판매가격이 아직 따라가지 못한 상태였기 때문입니다.

## 7. 주의할 점

- **인과효과가 아니라 "예측과의 차이"입니다.** 3월 13일 이후 판매가격을 바꾼 요인이 최고가격제뿐이라는 가정에 기대고 있습니다. 같은 시기에 주유소 마진이나 수급 여건이 달라졌다면 그 영향도 효과에 섞입니다.
- **관측 범위 밖으로 연장한 값입니다.** 2026년 2월까지 국제 경유가격의 최고치는 1,512원(2022년 6월)인데 3/22~3/26에는 평균 2,090원이었습니다. 등유도 마찬가지입니다. 이 구간의 가상 가격은 "선형 관계가 그 수준에서도 유지된다"는 가정의 산물입니다.
- **급등기에는 예측이 덜 정확합니다.** 4절의 2022년 검증에서 오차가 평상시의 3~4배였고, 실제보다 낮게 예측하는 쪽으로 치우쳤습니다.
- **시행 직전 며칠의 가격에 영향을 받습니다.** 잔차 보정은 3/6~3/12의 가격을 기준으로 삼습니다. 이 기간은 국제가격이 급등하던 때여서, 모형에 따라 보정 폭이 크게 다릅니다(5절).
- **통계적 유의성은 제시하지 않습니다.** 일간 가격은 자기상관이 매우 강해(더빈-왓슨 0.03~0.09) 일반 표준오차를 믿기 어렵습니다. 불확실성은 4절의 가상 시행일 검증 오차로 판단합니다.
- **먼 시점일수록 신뢰도가 낮아집니다.** `output/counterfactual_daily.csv`에는 2026년 10월까지의 가상 가격이 있지만, 시행 초기 몇 주를 넘어서면 마진·수요 여건이 표본 기간과 달라졌을 가능성이 커지고 잔차 보정의 근거도 약해집니다.
- **소비자물가에 미친 효과는 다루지 않습니다.** 판매가격에 미친 효과까지만 추정합니다.

## 8. 실행 방법

파이썬 3.9 이상이 필요합니다. 이 폴더(`kdi_regression`) 안에서 실행합니다.

```
pip install -r requirements.txt
python kdi_price_cap_replication.py             # 효과 추정과 KDI 표 1 비교
python kdi_price_cap_replication.py --validate  # 가상 시행일 검증 표 추가
```

분석용 자료 `data/opinet_daily.csv`는 저장소에 올리지 않으며, 처음 실행할 때 `input`의 원자료에서 자동으로 만들어집니다. 표본 시작일은 `--start 2022-01-01`처럼 바꿀 수 있고, 시차 모형과 비교 기간은 스크립트 상단의 설정에서 바꿉니다.

**폴더 구성**

```
kdi_regression/
├─ README.md
├─ requirements.txt
├─ build_dataset.py                 원자료를 합쳐 분석용 자료를 만듦
├─ kdi_price_cap_replication.py     회귀 추정, 가상 가격, KDI 표 1 비교, 검증, 그림
├─ input/                           오피넷에서 받은 원본 (수정하지 않음)
├─ data/opinet_daily.csv            분석용 일간 자료 (실행하면 만들어짐)
└─ output/                          실행 결과
   ├─ table1_comparison.csv         추정 결과와 KDI 표 1
   ├─ counterfactual_daily.csv      유종·날짜별 실제, 모형별 가상 가격, 중윗값, 효과
   ├─ model_stats.csv               모형별 계수 합, 조정 R², 잔차 보정
   ├─ validation.csv                가상 시행일 검증 결과
   └─ counterfactual.png            실제와 가상 가격 그림
```

**자료를 갱신하려면** 3절의 오피넷 메뉴에서 같은 항목을 일간으로 다시 내려받아 `input`의 파일을 같은 이름으로 덮어쓴 뒤 `python build_dataset.py`를 실행합니다. 국제 제품가격은 단위를 "원"으로 바꿔서 받아야 합니다.
