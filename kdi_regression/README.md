# 석유 최고가격제 효과 추정: KDI 표 1 재현

KDI 「석유 최고가격제와 유류세 인하의 효과」(중동 전쟁 대응 T/F 긴급 현안자료, 2026.4.22)의 〈표 1〉 "3월 4주 차 최고가격제 효과 추정"을 오피넷 공개 자료와 단순 회귀식으로 재현한 코드와 자료입니다.

## 1. 결과 요약

2026년 3월 4주 차(3/22~3/28, 1차 최고가격이 적용된 마지막 주), 단위는 원/리터입니다.

| 구분 | 휘발유 | 자동차용 경유 | 실내 등유 |
|---|---|---|---|
| 실제: 재현 / KDI | 1,819 / 1,819 | 1,816 / 1,816 | 1,509 / 1,509 |
| 가상: 재현 / KDI | 2,275 / 2,279 | 2,739 / 2,732 | 2,051 / 2,061 |
| 효과: 재현 / KDI | −456 / −460 | −923 / −916 | −541 / −552 |

- 실제 가격은 오피넷 주간 평균 판매가격과 소수점까지 일치합니다.
- 가상 가격은 세 유종 모두 KDI 값과 0.5% 이내입니다.
- 표본 기간과 시차 설정은 단순한 형태 가운데 표 1에 가장 가까운 것을 고른 것이며, KDI가 실제로 쓴 설정과 같다고 볼 근거는 없습니다(7절).

## 2. 분석의 생각

최고가격제의 효과를 알려면 "최고가격제가 없었다면 주유소 가격이 얼마였을까"를 알아야 합니다. 이 가격은 관측되지 않으므로 다음 순서로 추정합니다.

1. 최고가격제 시행 **이전** 자료로 "국제 제품가격이 주유소 판매가격에 반영되는 관계"를 회귀식으로 추정합니다.
2. 시행 **이후** 주에 실제 국제 제품가격을 이 식에 넣어, 평소 관계가 그대로 유지됐다면 형성됐을 **가상 가격**을 예측합니다.
3. **실제 가격 − 가상 가격**을 최고가격제의 효과로 봅니다. 음수이면 그만큼 가격이 낮아졌다는 뜻입니다.

## 3. 사용한 자료

모두 오피넷(한국석유공사 유가정보시스템, www.opinet.co.kr)에서 2026년 10월 9일에 내려받은 주간 자료이며, 기간은 2015년 1월 1주 ~ 2026년 10월 1주(614주)입니다. 원본은 `input` 폴더에 그대로 두었습니다.

| 파일 (`input`) | 오피넷 메뉴 | 내용 | 쓰임 |
|---|---|---|---|
| `retail_weekly.csv` | 국내유가통계 > 주유소 > 평균판매가격 | 보통휘발유·자동차용경유·실내등유 전국 평균 판매가격 (원/리터) | 종속변수, 실제 가격 |
| `intl_weekly_krw.csv` | 유가관련정보 > 국제유가 > 석유제품 | 휘발유(92RON)·경유(0.001%)·등유 싱가포르 현물가격 (원/리터) | 설명변수 |
| `intl_weekly_usd.csv` | 같은 화면 | 같은 가격의 달러/배럴 값 | 참고용 (회귀에 쓰지 않음) |
| `tax_gasoline.xls`, `tax_diesel.xls` | 유가관련정보 > 유류세 > 세금변동추이 | 변동일자별 유류세 합계 (원/리터, 부가세 제외) | 통제변수 |

`build_dataset.py`가 이 파일들을 합쳐 `data/opinet_weekly.csv`를 만듭니다. 이때 두 가지 처리를 합니다.

- **주차:** 오피넷의 "n월 k주"는 그 달의 k번째 수요일이 속한 일요일~토요일입니다. 예를 들어 2026년 3월 4주는 3/22~3/28입니다.
- **유류세:** 세금변동추이는 변동일자만 있으므로, 각 주 7일에 적용된 세액을 평균해 주간 값으로 바꿉니다. 주중에 세율이 바뀐 주는 일수로 가중됩니다. 등유는 표본 기간에 세율 변동이 없어 넣지 않습니다.

국제 제품가격은 오피넷이 원/리터로 환산해 제공하는 값을 그대로 씁니다. 따라서 환율 변동이 이미 반영돼 있고 환율 자료는 따로 필요하지 않습니다.

## 4. 회귀식과 설정

유종별로 다음 식을 최소자승법(OLS)으로 추정합니다.

```
판매가격(t) = a + b0·국제가격(t) + b1·국제가격(t−1) + … + bK·국제가격(t−K) + c·유류세(t) + 오차(t)
```

| 설정 | 값 | 이유 |
|---|---|---|
| 자료 주기 | 주간 | KDI 표 1이 "3월 4주 차" 기준 |
| 변수 형태 | 수준(원/리터) | 유류세가 리터당 정액이라 원 단위 전달이 자연스러움 |
| 시차 모형 | K = 0, 1, 2주 (모형 3개) | 국제가격이 반영되는 시차를 달리 가정한 모형을 비교하기 위해 |
| 추정 표본 | 2021년 11월 3주 ~ 2026년 3월 1주 (225주) | 시작: 유류세 인하 시행(2021.11.12) 후 첫 온전한 주. 끝: 최고가격제 시행(2026.3.13) 직전 주 |
| 대표값 | 세 모형 가상 가격의 중윗값 | KDI 표 1과 같은 기준 (모형별 추정치의 중윗값) |

- **시차를 넣는 이유:** 주유소는 국제가격을 즉시 반영하지 않고 1~2주에 걸쳐 반영합니다. 시차를 몇 주로 보느냐에 따라 급등기의 가상 가격이 달라지므로, 한 모형에 기대지 않고 세 모형의 중윗값을 씁니다.
- **유류세를 넣는 이유:** 표본 기간에 유류세 인하율이 여러 번 바뀌었고, 2026년 3월 27일에도 인하 폭이 커졌습니다. 유류세를 식에 넣으면 가상 가격에는 실제 유류세 경로가 그대로 반영되고, 최고가격제만 없는 상황을 가정하게 됩니다.

## 5. 추정 결과 읽는 법

`output/model_stats.csv`에 저장됩니다.

| 유종 | 모형 | 국제가격 계수 합 | 유류세 계수 | 조정 R² |
|---|---|---|---|---|
| 휘발유 | 시차 없음 / 1주 / 2주 | 0.94 / 1.05 / 1.13 | 0.52 / 0.70 / 0.82 | 0.66 / 0.77 / 0.83 |
| 자동차용 경유 | 시차 없음 / 1주 / 2주 | 0.92 / 1.01 / 1.06 | 0.54 / 0.81 / 0.94 | 0.77 / 0.86 / 0.91 |
| 실내 등유 | 시차 없음 / 1주 / 2주 | 0.61 / 0.71 / 0.74 | 없음 | 0.53 / 0.67 / 0.73 |

- **국제가격 계수 합:** 국제 제품가격이 리터당 1원 오르면 판매가격이 장기적으로 몇 원 오르는지입니다. 휘발유와 경유는 약 1원으로, 국제가격 변동이 거의 그대로 전달됩니다. 등유는 0.6~0.7원으로 전달이 약합니다.
- **시차 구조:** 시차를 넣은 모형에서는 계수가 대부분 가장 먼 시차(1~2주 전)에 실립니다. 주유소 가격이 1~2주 전 국제가격을 따라간다는 뜻입니다.
- **조정 R²:** 시차를 늘릴수록 높아집니다. 시차 없는 모형은 가격의 늦은 반응을 담지 못해 설명력이 낮습니다.
- **유류세 계수:** 세금 전달률로 해석하지 마세요. 이 식에서는 가상 가격이 세율 변화에 끌려가지 않게 하는 통제변수일 뿐입니다.

## 6. 결과 해석

**3월 4주 차 모형별 가상 가격 (원/리터)**

| 모형 | 휘발유 | 자동차용 경유 | 실내 등유 |
|---|---|---|---|
| 시차 없음 | 2,236 | 2,785 | 2,051 |
| 시차 1주 | 2,371 | 2,739 | 2,170 |
| 시차 2주 | 2,275 | 2,578 | 1,968 |
| 중윗값 | 2,275 | 2,739 | 2,051 |

- **효과의 뜻:** 휘발유 −456원은 "국제가격과 판매가격의 평소 관계가 유지됐다면 2,275원이었을 가격이 실제로는 1,819원이었다"는 뜻입니다. 가상 가격 대비 휘발유 20%, 경유 34%, 등유 26% 낮습니다.
- **불확실성의 크기:** 모형에 따라 효과는 휘발유 −416~−551원, 경유 −762~−969원, 등유 −459~−661원입니다. 중윗값 하나만 쓰지 말고 이 범위를 함께 제시하는 것이 안전합니다.
- **경유 효과가 큰 이유:** 3월 4주 국제 경유가격은 리터당 2,120원으로 2월 4주(837원)의 2.5배였습니다. 같은 기간 국제 휘발유가격은 714원에서 1,299원으로 올랐습니다. 눌러야 할 상승분이 경유에서 훨씬 컸습니다.

**주별 효과 (실제 − 가상 중윗값, 원/리터)**

| 주 | 휘발유 | 자동차용 경유 | 실내 등유 |
|---|---|---|---|
| 3월 2주 (3/8~14, 시행 2일 포함) | −9 | −155 | −274 |
| 3월 3주 | −370 | −652 | −398 |
| 3월 4주 | −456 | −923 | −541 |
| 4월 1주 | −383 | −984 | −625 |
| 4월 2주 | −351 | −1,044 | −625 |

시차를 넣은 모형일수록 초기 효과가 작고 이후 커지며, 3월 3주~4월 2주 4주간 효과의 합은 모형 간 차이가 크지 않습니다.

## 7. 주의할 점

- **인과효과가 아니라 "예측과의 차이"입니다.** 3월 13일 이후 판매가격을 바꾼 요인이 최고가격제뿐이라는 가정에 기대고 있습니다. 같은 시기에 주유소 마진이나 수급 여건이 달라졌다면 그 영향도 효과에 섞입니다.
- **관측 범위 밖으로 연장한 값입니다.** 추정 표본에서 국제 경유가격의 최고치는 1,473원(2022년 6월)인데 3월 4주에는 2,120원이었습니다. 등유도 마찬가지입니다. 이 구간의 가상 가격은 "선형 관계가 그 수준에서도 유지된다"는 가정의 산물입니다.
- **설정은 표 1에 맞춰 역산했습니다.** 표본을 2010년대부터 잡은 로그 회귀 등 전혀 다른 설정도 표 1을 1% 이내로 맞춥니다. 숫자 세 개만으로는 KDI의 설정을 특정할 수 없습니다.
- **등유는 표본 시작 시점에 민감합니다.** 시작을 2022년 1월로 옮기면 등유 가상 가격이 2,000원, 2021년 1월로 옮기면 2,390원이 됩니다. 휘발유와 경유는 같은 범위에서 1% 안팎으로 유지됩니다. `--sensitivity` 옵션으로 확인할 수 있습니다.
- **통계적 유의성은 제시하지 않습니다.** 주간 가격은 자기상관이 강해(더빈-왓슨 0.2~0.4) 일반 표준오차를 믿기 어렵습니다. 이 분석의 목적은 계수 검정이 아니라 예측입니다.
- **먼 시점일수록 신뢰도가 낮아집니다.** `output/counterfactual_weekly.csv`에는 2026년 10월까지의 가상 가격이 있지만, 시행 초기 몇 주를 넘어서면 마진·수요·환율 여건이 표본 기간과 달라졌을 가능성이 커집니다.
- **소비자물가에 미친 효과는 다루지 않습니다.** 표 1의 가격 효과까지만 재현합니다.

## 8. 실행 방법

파이썬 3.9 이상이 필요합니다. 이 폴더(`kdi_regression`) 안에서 실행합니다.

```
pip install -r requirements.txt
python kdi_price_cap_replication.py                # 표 1 재현
python kdi_price_cap_replication.py --sensitivity  # 표본·시차 설정별 민감도 표 추가
```

분석용 자료 `data/opinet_weekly.csv`는 저장소에 올리지 않으며, 처음 실행할 때 `input`의 원자료에서 자동으로 만들어집니다. 표본 기간은 `--start 2022-01-1 --end 2026-02-4`처럼 바꿀 수 있고, 시차 모형과 기준 주는 스크립트 상단의 설정에서 바꿉니다.

**폴더 구성**

```
kdi_regression/
├─ README.md
├─ requirements.txt
├─ build_dataset.py                 원자료를 합쳐 분석용 자료를 만듦
├─ kdi_price_cap_replication.py     회귀 추정, 가상 가격, 표 1 비교, 그림
├─ input/                           오피넷에서 받은 원본 (수정하지 않음)
├─ data/opinet_weekly.csv           분석용 주간 자료 (실행하면 만들어짐)
└─ output/                          실행 결과
   ├─ table1_comparison.csv         재현 결과와 KDI 표 1
   ├─ counterfactual_weekly.csv     유종·주별 실제, 모형별 가상 가격, 중윗값, 효과
   ├─ model_stats.csv               모형별 계수 합, 조정 R²
   ├─ sensitivity.csv               설정별 민감도
   └─ counterfactual.png            실제와 가상 가격 그림
```

**자료를 갱신하려면** 3절의 오피넷 메뉴에서 같은 항목을 주간으로 다시 내려받아 `input`의 파일을 같은 이름으로 덮어쓴 뒤 `python build_dataset.py`를 실행합니다. 세 CSV의 조회 기간은 서로 같아야 합니다.
