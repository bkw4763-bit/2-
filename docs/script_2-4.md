# 분석 2~4단계 발표 대본 (약 3분 5초, 실제 시연 포함)

최종 슬라이드 `docs/presentation_final.pptx` 17~28번 기준. 슬라이드 노트에도 같은 대본이 있습니다. 평가 기준(문제 정의 → 아이디어 → 개발·시현 → 결론)에 맞춰 AI 필요성, API 활용, 실제 시연, 결론을 넣었습니다.

**[17] 문제와 결론 · 11차 권고안 (15초)**
정부는 4주마다 휘발유·경유·등유 최고가격을 정합니다. 올리면 정부 지원금은 줄지만 물가가 오릅니다. 저희는 이 둘을 숫자로 따져, 다음 결정인 11차에 유종별로 몇 원을 조정할지 미리 권고하는 프로그램을 만들었습니다. 결론은 휘발유 30원, 경유 90원, 등유 120원 인상입니다.

**[18] 계산 흐름 (15초)**
지금까지 정부는 세 유종을 늘 같은 폭으로 조정했습니다. 저희 프로그램은 팀원이 만든 회귀 결과를 받아, 재정 부담, 물가 영향, 최적 조정 폭을 유종별로 차례로 계산합니다.

**[19] 재정 부담 6.35조 원 (20초)**
그래프는 정부가 매주 정유사에 리터당 지원한 금액입니다. 3~4월 경유는 1,000원을 넘었고, 6월 말 0 근처까지 내려왔다가 9월 말 다시 커졌습니다. 판매량을 곱해 더하면 9월 26일까지 6.35조 원이고, 71%가 경유입니다.

**[20] 반영률과 물가 검증 (20초)**
상한을 올려도 주유소 가격이 다 따라 오르지는 않습니다. 실제 두 번의 조정에서 4주 뒤 휘발유·경유는 약 90%, 등유는 39%만 올랐습니다. 이 방법으로 계산하면 상한제가 3~8월 물가를 0.58%p 낮췄는데, 정부 발표 0.6%p와 거의 같습니다. 기준 판매가는 오피넷 API로 오늘 값을 받아 씁니다.

**[21] 100원당 물가 영향 (10초)**
그래서 같은 100원을 올려도 물가 영향은 휘발유가 등유의 약 21배입니다. 휘발유는 적게, 경유와 등유는 많이 올리는 것이 유리합니다.

**[22] 최적화 방법 (20초)**
미래 유가는 알 수 없어서 몬테카를로 시뮬레이션을 썼습니다. 과거 유가와 환율의 움직임으로 24주 유가 흐름 500가지를 만들고, 216가지 조정안을 모두 적용해 10만 8천 번 계산합니다. 사람이 손으로 할 수 없는 계산이라 프로그램이 필요합니다.

**[23] 고르는 기준 (10초)**
고르는 기준은 한 달 물가 상승 0.104%p 이내에서 정부 지원금이 가장 적은 안입니다. 상한제가 낮춰 둔 물가를 여섯 번에 나눠 되돌리는 속도입니다.

**[24] 11차 권고 · 실제 시연 (25초)**
직접 실행해 보겠습니다. (터미널에서 python policy/optimize.py 실행) 오피넷에서 오늘 판매가를 받고, 몇 초 안에 권고가 나옵니다. 휘발유 30원, 경유 90원, 등유 120원 인상입니다. 이번 달 물가는 0.1%p 오르고, 지원금은 4주에 약 1,900억 원 줄어듭니다.

**[25] 동결 vs 권고 (10초)**
동결하면 앞으로 24주 지원금은 5.72조 원, 권고대로 하면 4.86조 원으로 약 8,600억 원 줄어듭니다.

**[26] 민감도 (10초)**
반영률, 물가 한도, 유가 흐름을 바꿔 다시 계산해도, 휘발유를 가장 적게 올린다는 결론은 8가지 모두 같았습니다.

**[27] 과거 결정 비교 (15초)**
같은 규칙을 과거 결정에 적용하면 정부보다 상한을 더 올렸을 것입니다. 정부가 재정보다 물가를 더 중시해 왔다는 뜻이고, 저희 권고는 재정까지 함께 고려한 비교 기준입니다.

**[28] 결론 (15초)**
정리하면, 유종마다 다르게 조정하면 같은 물가 부담으로 지원금을 더 많이 줄일 수 있습니다. 이 프로그램은 4주마다 최신 자료로 다시 돌려 다음 결정의 근거로 쓸 수 있습니다. 감사합니다.

## 예상 질문과 답

전체 질문 19개와 답은 Claude Docs 문서 「분석 2~4단계 발표 대본과 예상 질문」에 있습니다. 아래는 핵심 질문입니다.

- **물가 한도를 왜 0.104%p로 정했나요?** 상한제가 9월에 물가를 0.623%p 낮춰 두고 있습니다. 이것을 남은 여섯 번의 결정에 나눠 되돌리는 속도입니다. 정부가 실제로 한 2차 인상(0.375%p)의 3분의 1이 안 됩니다.
- **재정 부담이 업계 추산(4~5조 원)보다 큰 이유는요?** 기준 가격이 국제가·환율에 최근 52주 국내 가격 수준 보정까지 반영해, 정부의 '원가 + 적정 마진' 기준보다 높게 잡히기 때문입니다.
- **과거 결정과 하나도 안 맞는데 믿을 수 있나요?** 목표가 다릅니다. 정부는 물가를 우선했고, 이 도구는 물가 한도 안에서 재정을 줄이는 기준을 보여 줍니다.
- **휘발유 지원금액이 큰데 왜 30원만 올리나요?** 같은 100원을 올려도 휘발유는 물가를 등유의 약 21배 올립니다. 한 달 물가 한도 안에서 지원금을 가장 많이 줄이는 조합이 휘발유 30원, 경유 90원, 등유 120원입니다.
- **왜 AI/프로그램이 필요한가요?** 정부는 세 유종을 늘 같은 폭으로 조정해 왔습니다. 미래 유가 500가지 × 조정안 216가지 = 10만 8천 번 계산은 사람이 할 수 없고, 프로그램은 4주마다 최신 자료로 몇 초 만에 다시 계산합니다.
- **어떤 AI 알고리즘인가요?** 회귀 예측 → 몬테카를로 시뮬레이션 → 216가지 전수 비교 최적화. 딥러닝(TimesFM)은 회귀 예측을 검증하는 비교 모형입니다.
- **시연 중 인터넷이 끊기면요?** 저장본 → 주간 판매가 파일로 자동 대체하고, 어느 값을 썼는지 화면에 표시합니다.
