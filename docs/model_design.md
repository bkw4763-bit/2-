# 회귀 이후 단계(2~5단계) 모형 설정

`CLAUDE.md` 에 합의된 알고리즘을 바탕으로, 회귀 이후 단계의 모형 설정을 구현에 바로 쓸 수 있게 정리한 문서입니다.

- 숫자는 저장소 자료에서 확인한 값만 썼습니다. 아직 없는 값은 **미확인**으로 표시했습니다.
- 팀이 정해야 하는 값은 **결정 필요**로 표시했습니다.

---

## 0. 전체 구조

```
[1단계 회귀] ─ "없었다면" 공급가 계산기 (비중 w, 마진 m)
      │
      ├─ 과거 격차 ──────────→ [2단계 재정] ─→ 검증: 예산·업계 손실 추산과 대조
      │
      └─ 미래 국제가 경로 → 미래 격차 ─┐
                                      ├→ [4단계 최적화] → 11차 권고 → [5단계 권고문]
          상한 조정 → 판매가 → 물가 ───┘
               [3단계 물가]
```

권고는 두 비용을 맞바꾸는 계산입니다.
- 상한을 올리면 **재정 부담**(정부가 정유사 손실을 메우는 돈)이 줄어듭니다.
- 대신 **물가 부담**(소비자 가격 상승)이 늘어납니다.

## 1. 회귀가 넘겨줄 것: "없었다면" 가격 계산기

4단계는 과거가 아니라 **미래** 국제가로 격차를 계산해야 합니다. 그래서 회귀식을 함수로 넘깁니다(아직 미구현, 약 15줄).

```
counterfactual_from_intl(fuel, 주별 국제가 경로, 유류세) → "없었다면" 세후 공급가 경로
   = (m + w0·x_t + w1·x_(t−1) + w2·x_(t−2)) × 1.1 + 유류세
```

- 비중 w 와 마진 m 은 1단계 값을 그대로 씁니다. 새 가정은 없습니다.
- 미래 유류세는 현재 값(698.5 / 436.3 / 80.2원)을 유지합니다. 인하 연장 기한(11월 말) 이후는 **결정 필요**입니다.

## 2. 2단계: 재정 부담 (`fiscal.py`)

**식**

```
일별 재정 부담_f(t) = max(격차_f(t), 0) × 하루 판매량_f
격차_f(t)         = "없었다면" 세후 공급가_f(t) − 상한_f(t)
```

| 설정 | 내용 | 상태 |
|---|---|---|
| 격차가 음수인 날 | 상한이 걸리지 않음 → 부담 0 | 확정 |
| 주별 격차 → 일별 | 그 주 7일에 같은 격차를 적용. 상한이 주 중간에 바뀌면 일별 상한으로 다시 계산 | 확정 |
| 하루 판매량 `DAILY_VOLUME_L` | 유종별 리터/일. 석유공사 통계 | **미확인** |
| 판매량 변화 | 상한제 이후 판매량이 줄었다는 보도가 있음(8월까지 전년 대비 휘발유 −2.1%, 경유 −8.4%, **출처 미확인**). 상한제 기간 실제 판매량을 쓸지, 평년값을 쓸지 | **결정 필요** |

**산출**: 유종별 일별·주별·차수별·누적 재정 부담, 유종별 비중

**검증**: 3/13 ~ 9/26 누적 부담을 업계 추산 손실(4~5조 원, 정부 예산 4.2조 원. 둘 다 **출처 미확인**)과 비교합니다. 우리 격차는 업계 기준(국제 시세와의 차액)에 가깝습니다. 정부 기준(원가 + 적정 마진)은 더 작게 나오는 것이 정상입니다.

## 3. 3단계: 물가 영향 (`cpi.py`)

**① 반영률**: 상한을 바꾸면 판매가가 얼마나 따라가나

`CLAUDE.md` 의 '상한 조정 후 판매가 반응' 표를 비율로 바꾼 값입니다(판매가 변화 ÷ 상한 변화, 2차 +210원 / 7차 −150원).

| | 1주 | 2주 | 4주 |
|---|---|---|---|
| 휘발유 (2차 / 7차) | 53% / 67% | 81% / 83% | 89% / 90% |
| 경유 (2차 / 7차) | 51% / 69% | 80% / 87% | 88% / 95% |
| 등유 (2차 / 7차) | 27% / 17% | 40% / 23% | 50% / 29% |

| 설정 | 내용 | 상태 |
|---|---|---|
| 기본 반영률 | 두 차례의 4주 값 평균. 휘발유 약 90%, 경유 약 91%, 등유 약 39% | 확정 가능 (자료 있음) |
| 반영 속도 | 1·2·4주 경로를 그대로 써서 월 안에서의 시점 반영 | **결정 필요** (단순화하면 4주 값만) |
| 민감도 | 반영률 75~100% (독일 사례 범위) | 합의됨 |

**② 실효 인상폭 (중요한 설정)**

상한이 시장 가격("없었다면" 가격)보다 높아지면, 그 이상 올려도 실제 가격은 오르지 않습니다.

```
실효 공급가 변화 = min(새 상한, "없었다면" 가격) − min(기존 상한, "없었다면" 가격)
판매가 변화     = 실효 공급가 변화 × 반영률
```

이 설정이 없으면 격차보다 크게 올리는 안의 물가 비용을 과대 계산합니다.

**③ 물가 기여도**

```
물가 기여도(%p) = Σ_f (가중치_f / 1000) × (판매가 변화_f / 판매가_f) × 100
월 기여도      = 그 달의 일별 기여도 평균 (월 중간 조정은 일수만큼만 반영)
```

| 설정 | 내용 | 상태 |
|---|---|---|
| 가중치 `CPI_WEIGHTS` | 소비자물가 품목 가중치 (1000 기준) | **미확인** |
| 기준 판매가 | 오늘 전국 평균 판매가 (`policy/opinet.py`, 오피넷 API `avgAllPrice.do`). 실패하면 저장본(`data/opinet_latest.csv`) → 주간 판매가 파일 | 구현 |

**검증**: "상한제가 없었다면 판매가 = 실제 + 격차 × 반영률"로 3~8월 물가 차이를 계산해, 정부의 "평균 0.6%p 낮춤"과 대조합니다.

## 4. 4단계: 11차 결정 최적화 (`optimize.py`)

**문제 정의**

| 요소 | 설정 | 상태 |
|---|---|---|
| 결정 시점 | 11차부터 4주마다 6차수 (약 24주) | 합의됨 |
| 상태 | 유종별 현재 상한, 최근 3주 국제가(원/리터), 유류세 | 합의됨 |
| 행동 | 유종별 조정 폭 {−60, 0, +30, +60, +90, +120원} → 3유종 조합 6³ = 216가지 | 합의됨 |
| 목표 | 6차수 누적 재정 부담의 경로 평균 최소화 | 합의됨 |
| 제약 1 | 월 물가 기여도 ≤ 한도 | **결정 필요** (한도 값) |
| 제약 2 | 차수당 최대 인상폭 | **결정 필요** (행동 목록 상한 120원과 같게 할지) |
| 제약 3 | 상한을 "없었다면" 가격보다 크게 올리는 행동은 의미 없음 (실효 인상 0) | 3단계 ② 로 자동 반영 |

**미래 국제가 경로 만들기**

| 설정 | 내용 | 상태 |
|---|---|---|
| 방법 | 과거 주간 변화율을 4주 묶음으로 무작위 추출해 이어 붙임(블록 부트스트랩). 세 유종은 같은 주를 함께 뽑아 유종 간 상관 유지 | 제안 |
| 추출 기간 | 최근 3년 또는 상한제 이전 전체 | **결정 필요** |
| 경로 수 | 500개, 난수 시드 고정 (재현 가능) | 제안 |
| 환율 | 원/리터 국제가 안에 포함되므로 따로 만들지 않음 | 제안 |

**풀이 방법** (합의안: "평균 비용이 가장 낮은 첫 행동")

```
for 첫 행동 a (216가지):
    for 경로 p (500개):
        11차에 a 적용 → 12~16차는 단순 규칙으로 진행 → 24주 재정·물가 계산
    평균 재정 부담(a), 제약 위반 비율(a) 기록
권고 = 제약을 지키는 a 중 평균 재정 부담이 가장 작은 것
```

12~16차에 쓸 **단순 규칙은 결정 필요**입니다. 제안은 "물가 한도 안에서 격차가 큰 유종부터 허용되는 최대 인상"입니다. 설명하기 쉽고, 첫 행동의 차이만 비교하는 데 충분합니다.

**산출**: 11차 권고(유종별 조정 폭), 이번 달 물가 기여도, 4주 재정 절감액, 경로별 분포(그래프용)

## 5. 검증

| 검증 | 방법 | 비교 대상 |
|---|---|---|
| 과거 결정 재현 | 1~10차 각 결정일에 그때까지의 자료만으로 4단계를 돌려 권고 → 실제 결정과 비교 | 2차 +210원, 7차 −150원, 나머지 동결 |
| 정부 물가 효과 | 3단계 검증 | 3~8월 평균 0.6%p |
| 재정 규모 | 2단계 검증 | 업계 추산 4~5조 원 (**출처 미확인**) |
| 민감도 | 반영률 75~100%, 물가 한도 ±, 1단계 마진 기간 26/52/104주를 바꿔도 11차 권고가 유지되나 | 권고 유지 여부 |

과거 결정 재현의 쉬운 확인점: 7차(6/27) 무렵 격차는 작았습니다. 이 저장소의 `results/regression/full_sample/counterfactual.csv`(최근 마진 모형) 기준으로 6/20 종료 주는 휘발유 58, 경유 32, 등유 36원, 6/27 종료 주는 휘발유 48, 경유 −11, 등유 −45원입니다. (이전 정리의 '휘발유 19~46원'은 이 결과와 맞지 않아 뺐습니다.) 실제 재현(`--replay`)에서 재정 최소화 규칙은 7차에 인상을 권고해, 인하한 실제 결정과 다릅니다(아래 결과 참고).

## 6. 구현 상태와 실행 (이 저장소 기준)

5단계 권고문은 이번 범위에서 뺐습니다. 2~4단계는 `policy/` 에 있고, 1단계 결과(`results/regression/full_sample/counterfactual*.csv`)를 읽습니다.

```
python regression/full_sample/counterfactual.py      # 1단계 (결과가 이미 있으면 생략)
python policy/fiscal.py  [--volume 휘발유,경유,등유]   # 2단계 → results/policy/fiscal_weekly.csv, fiscal_summary.csv
python policy/cpi.py     [--weights 휘발유,경유,등유]  # 3단계 → results/policy/cpi_pass_through.csv, cpi_policy_effect.csv
python policy/optimize.py [--cpi-limit 값] [--sensitivity] [--replay]
python policy/plots.py                                # 그림 → results/policy/cpi.png, optimize.png, checks.png   # 4단계 → results/policy/optimize_*.csv
```

미확인 값은 `policy/config.py` 에 `None` 으로 두었습니다. 넣는 방법은 두 가지입니다: `config.py` 를 고치거나, 명령행 인자로 넣습니다.

**구현에서 정한 것 (위 설계에서 바뀌거나 구체화된 점)**

| 항목 | 구현 | 이유 |
|---|---|---|
| 격차 | 1단계 `gap` = "없었다면" 세후 − 실제 세후 공급가 | 상한이 걸린 주에는 실제 세후 공급가 ≈ 상한(9월 4주 차이 2~4원). 이 저장소에 차수별 상한 표가 없어도 계산 가능 |
| 첫 주 일수 | 3/14 종료 주는 2일(3/13~14)만. 전체 198일 | 시행일 기준 |
| 판매량 미확인 시 | "누적 리터당 부담(원·일/L)"을 출력. × 하루 판매량 = 원 | 숫자를 지어내지 않고, 값이 오면 곱하기만 하면 됨 |
| 반영률 | 2차·7차 비율 평균, 3주 = 2·4주 중간값. 월평균(1~4주 평균) 휘발유 79%, 경유 80%, 등유 32%. 4주 값은 90 / 91 / 39% | 월 물가 기여도는 월평균이므로 반영 속도 포함. `PASS_MODE="4w"` 로 단순화 가능 |
| 정부 0.6%p 대조 | 판매가 인하율 = max(격차,0) × 4주 반영률 ÷ 판매가 | 상한이 오래 유지된 효과이므로 4주 값 |
| 결정 시점 상태 | 국제가 파일의 최신 3주(9월 5주, 10월 1주 포함)로 "없었다면" 가격 계산. 10/10 기준 격차 휘발유 378, 경유 420, 등유 423원 | 공급가는 9월 4주까지만 공개 |
| 1단계 식 재현 | 9/26 "없었다면" 가격을 0.2원 이내로 재현 (계수 반올림 차이) | 미래 경로에 같은 식을 쓰는 근거 |
| 물가 기여도 계산 시점 | 결정 시점에 아는 최신 "없었다면" 가격으로 실효 인상폭 계산 | 첫 행동의 물가 비용이 경로와 무관하게 정해져 제약이 명확 |
| 인하 조건 | 격차가 60원 미만인 유종만 인하 가능 | 없으면 격차 큰 유종을 내려 물가 한도를 비우고 다른 유종을 올리는, 재정 부담을 키우는 해가 뽑힘. 7차(격차 48원) 인하와도 맞음 |
| 12~16차 규칙 | 격차 큰 유종부터, 남은 물가 한도 안에서 '격차 이하 최대 조정 폭'. 격차 ≤ −60 이면 −60, −60~0 이면 동결 | 설명 쉬움 |
| 경로 | 상한제 이전(2015~) 주간 로그 변화율 4주 블록, 세 유종 같은 주, 500개, 시드 42. 모든 행동이 같은 경로 사용(공통 난수) | 가격이 음수가 되지 않고, 행동 간 차이가 경로 운이 아니게 |
| 민감도 (`--sensitivity`) | 반영률 75%·100%·4주 값만, 한도 ×0.5·×1.5, 추출 기간 최근 3년, 다른 시드 | 권고 유지 여부 확인 |
| 판매량 | `csv/petroleum_sales_monthly_202608.csv` 월별(천 배럴, 팀 확인) ÷ 일수. 9월 이후는 전년 동월 × (올해 3~8월 ÷ 전년 3~8월) | 등유 겨울 증가와 상한제 이후 판매 감소를 함께 반영 |
| 물가 가중치 | `csv/cpi_weights_2020.xlsx`: 휘발유 24.1, 경유 16.3, 등유 2.4 (1000 기준) | 2020년 기준 품목 가중치 |
| 상한표 | `csv/caps.csv` (1~10차, 3·4·5·9차 시행일은 추정) | 과거 결정 재현 |
| 과거 결정 재현 (`--replay`) | 2~10차 시행일 전에 끝난 주의 국제가와 직전 상한만으로 권고, 실제와 방향 비교 | |

**월 물가 기여도 한도: 0.105%p (자료에서 계산)**

한도 = 최근 달(9월)에 상한제가 눌러 두고 있는 물가 0.630%p ÷ 남은 6차수 = 0.105%p.

- 뜻: 상한제로 눌러 둔 물가 효과를 24주 동안 같은 크기로 나눠 되돌립니다. 한 번에 물가가 튀지 않고, 기간 끝에는 상한 없는 가격에 닿을 수 있습니다.
- 근거: 3단계 검증(3~8월 0.57%p, 정부 0.6%p)을 통과한 계산에서 나온 값이라 임의로 정한 숫자가 아닙니다.
- 점검: 정부가 한 번 받아들인 최대 인상(2차 +210원)은 0.375%p 입니다. 한도는 그보다 낮고, 차수마다 꾸준히 지킬 수 있는 수준입니다.
- `--cpi-limit` 을 주면 그 값을 씁니다. 민감도에서 ×0.5, ×1.5 를 확인합니다.

**결과**

- 2단계: 3/13~9/26 누적 재정 부담 6.26조 원 (휘발유 1.56, 경유 4.48, 등유 0.22조). 업계 추산 4~5조 원보다 큽니다. 우리 기준은 '최근 마진(약 100원) 포함 시장가 − 상한'이라 손실을 넓게 잡습니다.
- 3단계 검증: 3~8월 평균 물가 인하 효과 0.57%p. 정부 설명 0.6%p 와 맞습니다.
- 4단계: 11차 권고 휘발유 +30원, 경유 +90원, 등유 +120원 / 이번 달 물가 +0.101%p (한도 0.105%p) / 4주 재정 절감 약 1,902억 원 (`results/policy/optimize_log.txt`).
- 민감도: 7가지 중 6가지에서 "휘발유는 적게(0~60원), 경유·등유는 많이(90~120원)" 올립니다. 반영률 75% 에서만 휘발유 +90, 경유 +60, 등유 +90원으로 바뀝니다. 같은 경로·다른 시드·최근 3년 추출에서는 권고가 그대로입니다.
- 과거 결정 재현: 방향 일치 0/9. 정부는 격차가 커도 동결하고, 격차가 작을 때(7차) 인하했습니다. 재정 부담 최소화 규칙은 격차가 있으면 올립니다. 정부가 실제로는 물가를 재정보다 훨씬 무겁게 본다는 뜻이며, 이 도구의 권고는 '재정을 고려하면 이만큼 올릴 여지가 있다'는 비교 기준으로 쓰는 것이 맞습니다.
