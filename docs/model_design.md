# 2~4단계 모형 설정 (최종)

1단계 "없었다면" 가격을 받아 재정 부담(2단계), 물가 영향(3단계), 11차 결정 최적화(4단계)를 계산합니다.
5단계 권고문은 범위에서 뺐습니다. 코드는 `policy/`, 결과는 `results/policy/` 에 있습니다.

```
[1단계] "없었다면" 세후 공급가 = (마진 m + 비중 w · 국제가 3주) × 1.1 + 유류세
   ├─ 과거 격차 ───────────→ [2단계] 재정 부담 → 검증: 업계 추산 손실
   └─ 미래 국제가 경로 500개 → [4단계] 216개 첫 행동 중 권고 ← [3단계] 상한 인상 → 판매가 → 물가
```

## 실행

```
python regression/full_sample/counterfactual.py    # 1단계 (결과가 있으면 생략 가능)
python policy/fiscal.py                            # 2단계
python policy/cpi.py                               # 3단계
python policy/optimize.py --sensitivity --replay   # 4단계 + 민감도 + 과거 결정 재현 (약 15초)
python policy/plots.py                             # 그림
```

## 2단계: 재정 부담 (`policy/fiscal.py`)

```
주별 재정 부담 = max(격차, 0) × 상한제 적용 일수 × 하루 판매량
격차 = "없었다면" 세후 공급가 − 실제 세후 공급가 (상한이 걸린 주에는 실제 공급가 ≈ 상한, 9월 4주 차이 2~4원)
```

- 첫 주(3/14 종료)는 3/13~14 이틀만 셉니다. 전체 198일.
- 하루 판매량 = 그 달 판매량(천 배럴) × 1000 × 158.987 ÷ 그 달 일수.
- 90% 구간은 1단계 격차 구간으로 같은 계산을 합니다.

**결과**: 3/13~9/26 누적 **6.26조 원** (휘발유 1.56, 경유 4.48, 등유 0.22조). 업계 추산 손실 4~5조 원(출처 미확인)보다 큽니다. 우리 격차는 최근 정유사 마진(약 100원)을 포함한 가격 기준이라 손실을 넓게 잡습니다.

## 3단계: 물가 영향 (`policy/cpi.py`)

**① 반영률** = 판매가 변화 ÷ 상한 변화. 2차·7차 평균이고, 3주는 2·4주 중간값입니다.

| | 1주 | 2주 | 3주 | 4주 | 월평균 |
|---|---|---|---|---|---|
| 휘발유 | 60 | 82 | 86 | 90 | 79 |
| 경유 | 60 | 83 | 87 | 91 | 80 |
| 등유 | 22 | 32 | 36 | 39 | 32 |

월 물가 기여도는 한 달 평균이므로 4단계에서는 월평균 반영률을 씁니다.

**② 실효 인상폭** = min(새 상한, "없었다면" 가격) − min(기존 상한, "없었다면" 가격). 시장 가격보다 높게 올린 부분은 판매가를 올리지 않습니다.

**③ 물가 기여도(%p)** = Σ 가중치/1000 × 실효 인상폭 × 반영률 ÷ 판매가 × 100.
상한 100원 인상의 물가 영향: 휘발유 0.103, 경유 0.071, 등유 0.005%p.

**검증**: "상한제가 없었다면 판매가 = 실제 + 격차 × 4주 반영률"로 계산한 3~8월 평균 물가 인하 효과 **0.57%p** (정부 설명 0.6%p).

## 4단계: 11차 결정 최적화 (`policy/optimize.py`)

| 요소 | 설정 | 이유 |
|---|---|---|
| 결정 | 11차부터 4주마다 6차수(24주) | 현재 4주 주기 |
| 행동 | 유종별 {−60, 0, +30, +60, +90, +120원} → 216가지. 차수당 최대 인상 120원 | 합의안 |
| 목표 | 24주 재정 부담의 경로 평균 최소 | 합의안 |
| 물가 한도 | 월 기여도 ≤ **0.105%p** = 9월 상한제 물가 억제 0.630%p ÷ 6차수 | 눌러 둔 물가를 24주에 걸쳐 고르게 되돌림. 3단계 검증을 통과한 값에서 계산. 실제 2차 +210원(0.375%p)보다 낮음 |
| 인하 조건 | 격차 60원 미만인 유종만 인하 | 없으면 격차 큰 유종을 내려 물가 한도를 비우고 다른 유종을 올리는, 재정 부담을 키우는 해가 나옴. 7차 인하(격차 48원)와 맞음 |
| 국제가 경로 | 상한제 이전(2015~) 주간 로그 변화율을 4주 묶음으로 뽑아 이어 붙임. 세 유종은 같은 주. 500개, 시드 42 | 가격이 음수가 되지 않고 유종 간 상관 유지. 모든 행동이 같은 경로 사용(공통 난수) |
| 미래 "없었다면" 가격 | 1단계 식 그대로. 앞 두 주는 실제 국제가 | 9/26 값을 0.2원 이내로 재현 |
| 결정 시점 정보 | 국제가 최신 3주로 계산한 "없었다면" 가격 | 공급가는 9월 4주까지만 공개 |
| 12~16차 | 격차 큰 유종부터 남은 물가 한도 안에서 '격차 이하 최대 조정 폭'. 격차 ≤ −60 이면 −60, −60~0 이면 동결 | 설명 쉬운 규칙 |
| 판매량 | 미래 주가 속한 달의 전년 동월 × (올해 3~8월 ÷ 전년 3~8월) | 등유 겨울 증가, 상한제 이후 판매 감소 반영 |
| 유류세 | 현재 값(698.5 / 436.3 / 80.2원) 유지 | 11월 말 이후 변경은 반영하지 않음 |

**결과 (10/10 국제가 기준)**

- 현재 격차(정부 지원금액): 휘발유 378, 경유 420, 등유 423원/리터
- **11차 권고: 휘발유 +30원, 경유 +90원, 등유 +120원**
- 이번 달 물가 +0.101%p (한도 0.105%p), 4주 재정 절감 약 1,902억 원, 24주 재정 부담 5.47조 → 4.61조 원 (약 8,653억 원 감소)

**민감도** (`--sensitivity`): 7가지 중 6가지에서 "휘발유는 적게(0~60원), 경유·등유는 많이(90~120원)". 반영률 75% 에서만 휘발유 +90, 경유 +60, 등유 +90원. 최근 3년 추출, 다른 시드에서는 권고 그대로.

**과거 결정 재현** (`--replay`): 2~10차 시행일 전에 끝난 주의 국제가와 직전 상한만으로 권고하면 실제 결정과 방향 일치 0/9. 정부는 격차가 커도 동결했고 격차가 가장 작던 7차에 인하했습니다. 정부가 재정보다 물가를 훨씬 무겁게 봐 왔다는 뜻이고, 이 도구의 권고는 "재정을 함께 고려하면 이만큼 올릴 여지가 있다"는 비교 기준입니다.
