입력 파일: `csv/merged_weekly_data_clean.csv`. 방법론: `regression_method.md` 와 같은 모형을 학습 구간에만 학습했습니다.
정책 이전 자료 전체로 학습한 분석은 `results/regression/full_sample/regression_report.md` 에 있습니다. 수치는 2026-10-10 실행 결과입니다.

python regression/train_test/split_regression.py    # 분할·학습·평가·정책 기간 적용 + 그림

## 3. 평가 구간 성적

| | 휘발유 | 경유 | 등유 |
|---|---|---|---|
| **최근 마진: MAE (MAPE)** | **15.7 (1.9%)** | **13.5 (1.5%)** | **18.0 (2.1%)** |
| 학습 구간 전체 회귀: MAE | 16.8 | 18.9 | 18.0 |
| naive (학습 끝 가격 유지): MAE | 38.6 | 46.3 | 53.0 |
| 기술 점수 (1 − 모형 / naive) | 0.59 | 0.71 | 0.66 |
| 1~32주 MAE / 편향 (정책 기간과 같은 길이) | 12.8 / +11.2 | 12.5 / +8.1 | 18.1 / +11.6 |
| 33주 이후 MAE / 편향 | 16.8 / −16.0 | 13.9 / −12.5 | 18.0 / −0.6 |
| 90% 구간 적중률: 1~32주 / 전체 | 94% / 97% | 97% / 97% | 94% / 96% |

- **모형이 평가 구간에서도 통합니다.** 학습 구간 안 검증 MAE(18.0 / 17.0 / 23.2원)보다 평가 MAE가 오히려 낮고, 국제가를 보지 않는 naive보다 오차를 59~71% 줄입니다.
- 다만 휘발유·경유의 평가 MAE가 낮은 것은 **평가 구간 가격이 조용했던 영향**이 큽니다. 공급가 주간 변화율 표준편차가 학습 구간 4.3 / 4.2 / 4.2%, 평가 구간 2.6 / 3.2 / 4.7%입니다. 등유는 평가 구간이 더 출렁였는데도 MAE가 낮은데, 학습 구간 검증에 오차가 큰 2020년(43원)이 들어 있기 때문입니다.
- **90% 구간은 다소 넓게 잡혔습니다** (적중률 94~97%). 구간을 만든 학습 구간이 더 출렁였기 때문입니다.
- **마진을 다시 잡지 않으면 시간이 갈수록 낮게 예측합니다.** 휘발유·경유는 33주 이후 편향이 −16원, −12원입니다. 2025년에 마진이 커졌는데 모형은 2023년 마진을 그대로 썼기 때문입니다. 마진이 추세 없이 움직인 등유는 편향이 없습니다. 이것이 방법론이 마진을 "정책 직전 52주"로 다시 잡는 이유를 평가 구간에서 확인한 결과입니다.
- 최근 마진 모형은 휘발유·경유에서 전체 회귀보다 낫고(15.7 vs 16.8, 13.5 vs 18.9), 마진 추세가 없는 등유에서는 같습니다.

**민감도** (비중 {수준, 차분} × 마진 {26, 52, 104주}):

| | 평가 MAE 범위 | 채택 사양 평가 MAE | 9/12 격차 범위 |
|---|---|---|---|
| 휘발유 | 13.3 ~ 15.7 | 15.7 | 160 ~ 182원 |
| 경유 | 11.9 ~ 16.6 | 13.5 | 333 ~ 348원 |
| 등유 | 18.0 ~ 20.6 | 18.0 | 281 ~ 299원 |

휘발유·경유는 마진 104주 사양이 평가에서 1.5~2.4원 더 낫습니다. 평가 성적을 보고 사양을 고르면 평가 구간을 학습에 쓴 셈이 되므로 채택 사양은 바꾸지 않았습니다.

**등유의 1:1 가정**: 학습 구간 차분 회귀 계수(합 0.83)를 정규화하지 않고 그대로 쓰면 등유 평가 MAE가 18.0원에서 21.5원으로 **나빠집니다.** 평가 구간은 1:1 정규화를 지지합니다. 그러나 이 가정 하나로 정책 기간 등유 격차가 평균 115원(46~231원, 9/12은 89원) 달라집니다. 국제가가 학습 범위를 크게 넘은 정책 기간에는 등유 격차의 불확실성이 90% 구간보다 큽니다.

## 5. 유종별 6가지 기준과 R² (학습 / 평가 / 평가(2026년 제외))

같은 항목을 세 구간에서 나란히 계산했습니다 (`split_diagnostics.csv`, 그림 `split_diagnostics.png` = 학습, `split_test_diagnostics.png` = 평가).

- **①~③ (자기상관·교차상관·변동률)**: 자료 자체의 성질이라 각 구간의 자료로 계산합니다.
- **④~⑥과 R²**: 학습 구간은 학습 구간 안 기점 이동 검증(22회 × 32주)과 표본 안 회귀입니다. 평가 구간은 **학습 구간에서 정한 계수·마진을 고치지 않고** 적용한 표본 밖 값입니다. ⑥은 평가 구간에 4주마다 22개 기점을 두었고, naive는 기점 직전 실제 가격을 써서 모형에 불리한 비교입니다.
- **평가(2026년 제외)**: 평가 구간 끝 10주(2026년 1~3월 급등기)는 주간 변화가 매우 커서(첨도 17~34) 상관과 R²를 좌우합니다. 이 10주를 뺀 106주도 따로 봤습니다.

### 학습 구간의 결론이 평가 구간에서도 유지되는가

| 기준 | 질문 | 학습 구간 판정 | 평가 구간 |
|---|---|---|---|
| ① ACF | 휘발유의 과거 가격 의존성이 더 강한가? | 아니다 (휘발유 ≈ 경유 > 등유) | **유지.** 지난주 변화를 더해도 R²는 0.03~0.09만 늘어, 자기상관은 여전히 국제가를 늦게 따라가며 생긴 것입니다. 등유는 2024~2025년에 4주 주기(0.34)가 강해졌습니다 |
| ② CCF | 반영 시차가 제품별로 다른가? | 시차는 같고(1주), 등유는 덜 반영됨 | **휘발유·경유는 유지(1주), 반영은 조금 빨라짐**(평균 1.0~1.1주 → 0.7~0.9주). 평가 전체에서 경유·등유가 "같은 주"로 바뀐 것은 2026년 급등기 때문입니다. **등유는 2024~2025년 주간 반영이 거의 끊김** (최고 상관 0.27, 6주 누적 0.60) |
| ③ 변동률 | 경유·등유가 더 불규칙한가? | 아니다. 등유는 마진만 더 흔들림 | **등유는 그렇게 바뀜.** 국제가 변동은 세 유종이 같은데(3.2~3.3%) 국내 등유만 3.4%로 휘발유·경유(2.0~2.1%)보다 크고, 마진 변화(30원)가 2.5배입니다. 국제가가 아니라 국내 요인입니다. 평가 전체의 첨도 17~34는 2026년 급등기 10주 때문입니다 |
| ④ 잔차 | 경유·등유에서 특정 시기에 오차가 집중되는가? | 등유는 그렇다 (2020년) | 휘발유·경유는 2026년 급등기에 오차가 몰립니다(1.6~1.8배). 급등기를 빼면 세 유종 모두 1.1~1.2배로, 특정 시기 집중이 없습니다. 등유의 표본 밖 오차는 주마다 방향이 바뀝니다(1주 자기상관 0.16~0.18). 이는 오차가 지속적인 치우침이 아니라 주별 잡음이라는 뜻입니다 |
| ⑤ 변수 중요도 | 휘발유 입력변수의 설명력이 더 높은가? | 아니다 (경유 > 휘발유 > 등유) | **유지** (0.60 > 0.54 > 0.01). 휘발유·경유는 여전히 1주 전 국제가가 핵심입니다 |
| ⑥ Naive 비교 | 이전 값과 비슷해서 휘발유 예측이 쉬운가? | 1주 앞은 그렇다, 32주 앞은 아니다 | **유지.** 휘발유는 세 구간 모두 주간 변화가 가장 작고 1주째 기술 점수가 가장 낮습니다. 32주 기술 점수는 0.66~0.77로 학습 구간보다 낮지만, 이는 조용한 시기라 naive 오차가 작았기 때문입니다 |

### R² (휘발유 / 경유 / 등유)

| R² | 학습 (표본 안) | 평가 (표본 밖) | 평가(2026년 제외, 표본 밖) |
|---|---|---|---|
| 수준: 채택 모형 (참고) | 0.985 / 0.986 / 0.985 | 0.83 / 0.90 / 0.84 | 0.85 / 0.91 / 0.80 |
| 주간 변화: 채택 모형 비중 | 0.47 / 0.54 / 0.37 | 0.57 / 0.75 / 0.46 | 0.45 / 0.58 / −0.01 |
| 주간 변화: 학습 구간 차분 회귀 계수 | 0.49 / 0.55 / 0.40 | 0.63 / 0.72 / 0.38 | 0.54 / 0.60 / **0.01** |
| 주간 변화: 그 구간에서 다시 추정 (참고) | 0.49 / 0.55 / 0.40 | 0.66 / 0.80 / 0.54 | 0.58 / 0.63 / 0.08 |
| **4주 변화: 채택 모형 비중** | 0.89 / 0.92 / 0.87 | 0.89 / 0.93 / 0.79 | 0.89 / 0.92 / **0.69** |
| **13주 변화: 채택 모형 비중** | 0.96 / 0.98 / 0.96 | 0.93 / 0.96 / 0.89 | 0.93 / 0.96 / **0.90** |

- **수준 R²**는 학습 구간 0.99에서 평가 구간 0.80~0.91로 내려갑니다. 수준 R²는 표본 안에서 단위근 때문에 부풀려지므로 0.99를 근거로 쓰면 안 된다는 점이 표본 밖에서 확인됩니다.
- **휘발유·경유의 주간 변화 R²는 표본 밖에서도 학습 구간과 같은 수준입니다** (2026년 제외 0.54 / 0.60, 학습 0.49 / 0.55). 계수가 과적합되지 않았다는 뜻입니다. "다시 추정"과의 차이가 0.03~0.05뿐이라 계수도 안정적입니다. 급등기를 넣으면 R²가 오히려 오르는데(0.63 / 0.72), 큰 변화일수록 국제가대로 반영되기 때문입니다.
- **등유는 2024~2025년에 주 단위 설명력이 사라졌습니다** (표본 밖 0.01, 다시 추정해도 0.08). 하지만 4주 변화 0.69, 13주 변화 0.90으로, **몇 주 이상 길게 보면 여전히 국제가를 따라갑니다.** 주 단위 움직임에 국내 요인의 잡음이 커진 것입니다.
- "없었다면" 가격은 29주에 걸친 수준이므로, 정책 분석에 중요한 것은 4주·13주 R²입니다. 세 유종 모두 평가 구간에서 0.69~0.96을 유지합니다.

## 7. 종합

1. **학습 구간만으로 만든 모형이 처음 보는 평가 구간 116주에서도 통합니다.** MAE 13.5~18.0원, naive 대비 오차 59~71% 감소, 90% 구간 적중률 94~97%입니다. 전체 기간으로 학습해 구한 성적이 과적합 때문이 아니라는 근거입니다.
2. **유종 간 난이도 순서(경유 ≤ 휘발유 < 등유)도 평가 구간에서 유지됩니다.** 사진의 전제인 "휘발유가 가장 쉽다"는 이 분할에서도 성립하지 않습니다.
3. **전체 기간 분석에서 등유가 "가장 불규칙하다"(첨도 7.8)고 본 결과는 학습 구간에서는 나타나지 않습니다.** 학습 구간에서 등유는 가격 변동이 휘발유·경유와 같고, 마진 변동과 덜 완전한 반영(6주 누적 0.88)이 어려움의 원인입니다. 첨도를 키운 큰 출렁임은 2026년 1~3월 급등기 10주에서 나왔습니다.
4. **6가지 기준의 결론은 평가 구간에서도 대부분 유지됩니다.** 다만 등유는 2024~2025년에 국내 요인 때문에 주 단위로 국제가와 따로 움직였습니다(주간 변화 표본 밖 R² 0.01). 4주·13주로 보면 여전히 국제가를 따라갑니다(R² 0.69, 0.90). 휘발유·경유의 주간 변화 R²는 표본 밖에서도 0.54 / 0.60으로 학습 구간(0.49 / 0.55)과 같습니다.
5. **정책 기간의 최종 수치는 전체 기간 모형(`full_sample`)을 쓰는 것이 맞습니다.** 분할 분석은 방법이 통하는지 확인하는 용도입니다. 학습 80% 모형은 마진이 2년 넘게 묵어 휘발유·경유 격차를 16~21원 낮게 잡고, 평가 구간에서 같은 크기의 편향이 확인됐습니다. 전체 기간 모형은 이 문제를 피하려고 정책 직전 52주로 마진을 다시 잡습니다.

## 8. 한계

- **평가 구간이 조용했습니다.** 2024~2025년은 휘발유·경유 변동이 학습 구간의 절반 수준이라 평가 MAE가 실제 정책 기간 성적보다 낙관적일 수 있습니다. 2026년 1~3월 급등기는 평가 구간 끝 10주에만 들어 있습니다 (2026년 MAE 28.9 / 21.7 / 15.7원).
- **등유의 1:1 가정**: 학습 구간에서 기각됐고(p 0.000), 이 가정에 따라 정책 기간 등유 격차가 평균 115원 달라집니다. 평가 구간은 1:1 쪽을 지지하지만, 학습 범위를 크게 넘는 국제가에서는 확인할 수 없습니다.
- **등유의 주별 격차는 잡음이 큽니다.** 2024~2025년 국내 등유는 주 단위로 국제가와 따로 움직였으므로, 정책 기간 등유 격차는 한 주 값보다 몇 주 평균으로 읽는 편이 안전합니다.
- **평가는 한 번뿐입니다.** 116주 하나의 경로이므로, 시기를 옮겨 반복하는 기점 이동 검증(학습 구간 22회, 전체 기간 31회)보다 표본 변동에 약합니다. 두 결과를 함께 보는 것이 좋습니다.
- 그 밖의 한계(외삽, 상한 자료 없음, 2017-10-07 주 제외)는 전체 기간 보고서와 같습니다.
