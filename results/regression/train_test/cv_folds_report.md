# 학습셋 교차검증과 공통 평가셋에서의 예측오차 비교

## 1. 설계

- 자료·변수·분할: 딥러닝과 regression 모두 `regression/full_sample/counterfactual.py` 방식 (달력 연속 주별 표, 국제가 같은 주·1주 전·2주 전, 환율 없음, 정책 이전만).
- 평면 A (학습셋 안 교차검증): `results/timesfm_cv_aligned`의 기점 22개 × 예측 32주, 기점 간격 13주 (2017년12월4주 기준 ~ 2023년03월4주 기준). 기점마다 그 이전 자료만 사용.
- 회귀 재적합 점검: 예측 파일의 회귀 값을 counterfactual 경로로 다시 적합해 비교. 최대 차이 0.0001원 (허용 0.01원).
- 평면 B (공통 평가셋): `apply_common_test.py`의 정책 이전 뒤 20% (`split_regression.py`와 같은 경계). 학습 경계에서 한 번 고정.
- 모든 모형에 예측 구간의 **실제** 국제가를 넣었으므로 국제가가 주어진 조건부 예측입니다.
- 편향 = 예측 − 실제. skill = 1 − exp(평균 log(MAE / 무변화 MAE)).
- 기점별 차이의 유의성 검정(Diebold-Mariano)은 `results/timesfm_cv_aligned/cv_report.md`에 있습니다.

## 4. 읽는 법

- 평면 A와 B의 MAE를 직접 비교하지 마세요. A는 기점마다 재적합하고 예측 거리가 짧으며, B는 학습 경계에서 한 번 고정해 끝까지 밀고 갑니다.

- 평면 B는 regression 폴더 `split_report.md`의 평가 구간과 같은 주이므로 그 보고서 수치와 직접 비교할 수 있습니다.
