# 회귀분석 비교: 팀원 모형(`ols 111`) vs 우리 모형(`regression/`)

두 분석 모두 `csv/merged_weekly_data_clean.csv` 로 정유사 세전 공급가를 국제가로 설명합니다. 같은 자료에서 결과가 어떻게 다르고 왜 다른지 정리했습니다. 수치는 2026-10-10 실행 결과입니다.

```
python regression/comparison/compare_ols111.py
```

- 팀원 코드는 고치지 않았습니다. 그대로 실행한 결과가 저장소에 올라 있는 팀원 결과 파일(`csv/regression_*.csv`, `results/회귀/*.md`)과 한 글자도 다르지 않음을 확인했습니다.
- 결과 파일: `team_model_as_is.csv`, `same_conditions.csv`, `policy_gap.csv`, `fx_vs_margin.csv`, `compare_ols111.png` (이 폴더)

## 1. 설계 비교

| 항목 | 팀원 모형 (`ols 111`) | 우리 모형 (`regression/`) |
|---|---|---|
| 목적 | 국제가의 국내 세전가 전가율 추정 | "상한제가 없었다면" 공급가 (반사실 가격) |
| 식 | 세전가 = 절편 + b·국제가(1주 전) + c·환율(이번 주) | 세전가 = 마진 + Σ 비중·국제가(같은 주·1주 전·2주 전), 비중 합 = 1 |
| 상수 | OLS 절편 그대로 | 정책 직전 52주 평균 마진으로 다시 잡음 |
| 국제가 등급 | 경유(0.001%), 휘발유(92RON), 등유 | 같음 |
| 자료 범위 | 611주 전체 (정책 기간 29주 포함) | 정책 이전만 학습·평가, 정책 기간은 적용만 |
| 분할 | 시간순 80/20: 학습 2015-01 ~ 2024-05 (488주), 평가 2024-06 ~ 2026-09 (122주) | 시간순 80/20: 학습 ~2023-12 (462주), 평가 ~2026-03 (116주), 기점 이동 검증 31회 |
| 빠진 주(2017-10-07) | 행 단위 시차 (한 행만 2주 전 값) | 달력 기준 (3주 학습 제외) |
| 자기상관 대응 | 수준 회귀 + Newey-West 표준오차 | 차분 회귀 + Newey-West, 수준 R²는 근거로 쓰지 않음 |
| 주된 평가 지표 | R², RMSE, MAE, MAPE | 표본 밖 MAE·편향, 90% 구간 적중률 |

## 2. 팀원 모형 그대로: 평가 구간을 정책 이전과 정책 기간으로 나누면

팀원 보고서의 평가 R²는 휘발유 0.09, 경유 −1.10, 등유 −0.66입니다. 같은 예측을 두 기간으로 나누면 다음과 같습니다.

| 세전 원/리터 | 휘발유 | 경유 | 등유 |
|---|---|---|---|
| 평가 122주 전체: R² / MAE | 0.09 / 51.2 | −1.10 / 103.3 | −0.66 / 107.1 |
| **정책 이전 93주: R² / MAE / 편향** | **0.77 / 12.7 / −5.5** | **0.70 / 17.4 / −12.9** | **0.44 / 30.9 / +20.9** |
| 정책 기간 29주: 평균 (예측 − 실제) | +174.9 | +374.7 | +346.7 |

- **평가 R²가 음수인 것은 모형이 틀려서가 아니라 정책 효과 때문입니다.** 팀원 README에도 이렇게 적혀 있습니다. 정책 이전 93주만 보면 휘발유·경유는 잘 맞습니다.
- 정책 기간의 "예측 − 실제"(세전 175 / 375 / 347원)는 그 자체가 "상한제가 없었다면"과의 차이입니다. 그래서 정책 기간은 모형 평가가 아니라 격차 계산에 써야 합니다.

## 3. 같은 조건 비교

팀원 모형에서 우리 모형까지 한 가지씩만 바꾼 다섯 모형을 같은 학습 행으로 학습했습니다. 평가 방법은 세 가지입니다. 아래 표는 MAE(괄호는 편향, 예측 − 실제)이고, 단위는 세전 원/리터입니다.

| 모형 | (가) 팀원 분할의 정책 이전 93주 | (나) 우리 분할 116주 | (다) 기점 이동 검증 31회 × 32주 |
|---|---|---|---|
| ① 팀원 모형: 국제가(1주 전) + 환율 | **12.7** (−5.6) / **17.5** (−13.1) / 30.8 (+20.7) | 15.5 (+6.9) / 16.3 (−6.1) / 35.3 (+28.2) | 22.1 (−7.4) / 23.4 (−11.2) / 30.0 (−8.5) |
| ② ①에서 환율 제외 | 19.7 (−17.5) / 23.9 (−22.1) / 23.0 (−3.2) | 18.7 (−9.0) / 21.9 (−17.0) / 22.3 (−0.1) | 22.7 (−14.0) / 23.8 (−15.1) / 30.0 (−19.0) |
| ③ ②를 시차 0·1·2주로 | 17.5 (−15.9) / 20.9 (−19.5) / **18.2** (−0.2) | 16.8 (−7.4) / 18.9 (−14.7) / 18.0 (+2.7) | 20.9 (−13.2) / 21.2 (−14.2) / 28.3 (−18.4) |
| ④ ②에 최근 마진 | 20.2 (−18.9) / 21.4 (−19.3) / 23.9 (−9.0) | 17.3 (−9.1) / 16.8 (−8.7) / 22.4 (+0.6) | 18.4 (−3.9) / 17.9 (−4.1) / 23.7 (−1.7) |

주간 변화 R²(예측 공급가의 주간 변화가 실제 주간 변화를 설명하는 정도, 표본 밖)는 다음과 같습니다.

| | (가) 팀원 분할 93주 | (나) 우리 분할 116주 |
|---|---|---|
| ① 팀원 모형 | 0.15 / 0.03 / −0.12 | 0.13 / 0.05 / −0.11 |
| ⑤ 우리 모형 | 0.61 / 0.78 / 0.53 | 0.57 / 0.76 / 0.46 |

### 읽는 법
- **평가 구간을 한 번만 나누면 결과가 구간에 따라 바뀝니다.** 팀원 분할(가)에서는 휘발유·경유에서 팀원 모형이 앞서고(12.7 vs 18.8, 17.5 vs 19.2), 우리 분할(나)에서는 휘발유가 비슷하며 경유·등유는 우리 모형이 앞섭니다.
- **2018년부터 31번 반복한 기점 이동 검증(다)에서는 우리 모형이 세 유종 모두 오차가 23~32% 작습니다** (17.0 vs 22.1, 15.8 vs 23.4, 22.1 vs 30.0). 한 구간의 우연을 가장 덜 타는 비교입니다.
- **차이를 만든 것은 순서대로 ① 마진 재설정, ② 시차 구조입니다.** 기점 이동 검증 기준으로 보면 다음과 같습니다.
  - 최근 마진(② → ④): MAE 4.3 / 5.8 / 6.3원 감소, 편향 −14 ~ −19원 → −2 ~ −4원
  - 시차 0·1·2주(② → ③): MAE 1.8 / 2.6 / 1.7원 감소
  - 환율(② → ①): MAE는 거의 그대로(0.0 ~ 0.6원)이고, 편향만 −14 / −15 / −19원 → −7 / −11 / −8원으로 줄어듭니다
- **팀원 모형은 주 단위 움직임을 거의 설명하지 못합니다** (주간 변화 R² 0.03 ~ 0.15, 등유는 음수). 1주 전 국제가 하나에 계수 약 1을 주어, 실제로는 3주에 걸쳐(약 0.3 / 0.45 / 0.2) 나뉘는 반영을 한 주에 몰아넣기 때문입니다. 몇 달 단위 수준은 맞아도 주별 값은 출렁입니다.
- 팀원 분할(가)에서 팀원 모형이 앞선 것은 환율 덕분입니다. 2024년 하반기 이후 환율과 정유사 마진이 함께 올라, 환율 항이 마진 상승을 일부 대신 맞혔습니다(4장). 이 관계가 늘 성립하지는 않아서 31개 기점 전체에서는 우위가 사라집니다.

## 4. 환율 계수는 무엇을 잡는가

국제가가 이미 원화(달러 가격 × 환율)이므로 환율의 경제적 효과는 국제가 안에 들어 있습니다. 그런데도 팀원 모형의 환율 계수는 양(+)입니다(휘발유 0.066, 경유 0.051, 등유 0.137). 같은 기간(2015년 → 2023년)의 마진 변화와 비교하면 다음과 같습니다.

| | 휘발유 | 경유 | 등유 |
|---|---|---|---|
| 우리 모형 마진 (2015 → 2023) | 58 → 80원 (+22) | 68 → 102원 (+34) | 76 → 89원 (+14) |
| 환율 계수 × 환율 변화 (1,133 → 1,306원) | +11.5원 | +8.8원 | +23.8원 |
| 마진과 환율의 상관 | 0.45 | 0.50 | 0.12 |

- 휘발유·경유에서 환율 항은 **마진 상승의 일부(1/2, 1/4)를 대신 설명하는 추세 변수** 역할을 합니다.
- 등유에서는 환율 항(+24원)이 실제 마진 상승(+14원)보다 크고 마진과의 상관도 0.12뿐입니다. 그래서 환율이 1,400원대로 오른 평가 구간에서 등유를 20~28원 높게 예측합니다(3장 편향).
- 따라서 팀원 보고서의 "환율의 추가 효과는 등유에서만 유의하다"는 결론을 환율의 경제적 효과로 읽으면 안 됩니다. 가격 수준끼리의 회귀는 공적분이 확인되지 않았기 때문에(우리 점검 Engle-Granger p 0.10 / 0.49 / 0.27), Newey-West를 써도 수준 계수의 p값을 그대로 믿기 어렵습니다.

## 5. 정책 기간 격차 ("없었다면" 세후 − 실제 세후 공급가, 원/리터)

| 주 | 휘발유: 팀원 / 팀원 구성(전체 학습) / 우리 | 경유 | 등유 |
|---|---|---|---|
| 03-28 | 628 / 630 / 551 | 1,083 / 1,085 / 1,068 | 1,011 / 1,002 / 935 |
| 06-27 | 17 / 22 / 48 | −63 / −50 / −11 | −76 / −96 / −45 |
| **09-12** | **166 / 167 / 184** | **352 / 352 / 360** | 276 / 271 / 289 |
| 09-26 | 367 / 367 / 336 | 615 / 614 / 512 | 498 / 493 / 432 |
| 정책 기간 평균 | 192 / 195 / 191 | 412 / 417 / 404 | 381 / 370 / 371 |

- **정책 기간 평균 격차는 두 모형이 거의 같습니다** (차이 1 ~ 13원). 9/12 격차도 둘 다 정부 설명("휘발유 100원대 후반, 경유 300원대 중반 이상")과 맞습니다.
- **국제가가 빠르게 움직이는 주에는 크게 갈립니다.** 9/26 경유는 615원 vs 512원입니다. 팀원 모형은 1주 전 국제가를 거의 그대로 반영하고, 우리 모형은 3주에 나눠 반영하기 때문입니다. 3장의 주간 변화 R²(0.03 vs 0.78)를 보면, 실제 공급가는 3주에 나눠 반영하는 쪽에 가깝게 움직였습니다.
- 팀원 모형을 2024-05까지 학습하든 정책 이전 전체로 학습하든 격차는 거의 같습니다. 두 모형의 차이는 학습 기간이 아니라 모형 구성에서 나옵니다.

## 6. 두 분석이 일치하는 점

- 국내 기준 등급 선택(경유 0.001%, 휘발유 92RON)과, 세후가·주유소가처럼 결과가 거꾸로 들어가는 변수 제외
- 시간순 분할, 잔차 자기상관 확인과 Newey-West 보정
- **국제가 1원 → 국내 세전가 약 1원**: 팀원 수준 회귀 0.96 ~ 1.02, 우리 차분 회귀 0.88 ~ 1.01

## 7. 종합

1. **정책 분석("없었다면" 가격과 격차)에는 우리 모형이 더 적합합니다.** 31개 기점 검증에서 오차가 23~32% 작고 편향이 거의 없으며(−2 ~ −4원), 주 단위 움직임도 맞습니다. 차이의 대부분은 마진을 최근 값으로 다시 잡은 데서, 나머지는 시차를 3주로 나눈 데서 나옵니다.
2. **팀원 모형은 "전가율이 약 1"이라는 설명용 결론에 쓸 수 있고, 그 결론은 우리 결과와 같습니다.** 다만 다음 세 가지는 고쳐 읽는 것이 좋습니다.
   - 평가 R² 음수는 정책 효과이므로 정책 이전 주로만 평가합니다 (R² 0.77 / 0.70 / 0.44).
   - 환율 계수는 환율 효과가 아니라 마진 추세의 대리변수입니다. 빼도 MAE는 거의 그대로입니다.
   - 학습 R² 0.98~0.99는 가격 수준의 단위근 때문에 높게 나온 값이므로 근거로 쓰지 않습니다. 표본 밖 MAE나 주간 변화 R²를 씁니다.
3. 한 번 나눈 평가 구간의 성적은 구간에 따라 순위가 바뀝니다((가)와 (나)). 모형을 고를 때는 기점 이동 검증처럼 여러 시기를 반복한 결과를 기준으로 삼는 것이 안전합니다.
