# 최근 마진 회귀와 딥러닝 모델 비교

## 핵심 결과

현재 regression 코드가 기본으로 채택한 **최근 마진 회귀**와 **국제가격을 사용하는 TimesFM 3.0 딥러닝** 두 모델을 비교했다. 같은 조건에서 평가했을 때 최근 마진 회귀의 평균 절대오차는 **19.4050원/리터**, 딥러닝은 **20.6999원/리터**였다. 회귀의 오차가 약 **1.2949원/리터, 6.26% 낮았다.**

이는 ‘정확도가 6.26% 높다’는 뜻이 아니라 **평균 예측오차가 딥러닝 대비 6.26% 줄었다**는 뜻이다. 모든 시점에서 회귀가 더 정확했다는 의미도 아니다.

## 두 모델은 어떻게 예측하는가

**최근 마진 회귀**는 이번 주·1주 전·2주 전 국제가격의 회귀계수를 구하고 그 합을 1로 맞춘다. 그다음 학습 구간 마지막 52주 동안의 ‘국내 세전 공급가격 − 국제가격 가중평균’을 평균 내 예측에 더한다.

> 예측 공급가격 = 국제가격의 가중평균 + 최근 52주의 평균 마진

예를 들어 국제가격 가중평균이 700원이고 최근 평균 마진이 100원이면 800원/리터로 예측한다. 여기서 마진은 운송·정제 비용 등도 포함할 수 있는 가격 차이이며, 정유사의 순이익과 같지는 않다. 현재 `regression/full_sample/counterfactual.py`의 기본 설정은 `CHOSEN = "recent_margin"`이다.

**TimesFM 딥러닝**은 외부 자료로 미리 학습된 모델에 과거 국내 가격과 국제가격을 입력해 예측한다. 이번 평가에서는 사전학습 가중치를 고정하고, 각 기점까지의 가격 이력을 문맥으로 제공했다. 비교 대상은 국제가격 정보를 사용하는 `timesfm_cov`이며, 국제가격을 사용하지 않는 단변량 모델은 이 문서의 비교에 포함하지 않는다.

## 비교 조건은 같은가

**평가 문제와 채점 기준은 같지만, 모델의 학습 방식과 사전학습 이력까지 같은 것은 아니다.**

| 비교 항목 | 최근 마진 회귀 | TimesFM 딥러닝 | 판단 |
| --- | --- | --- | --- |
| 예측 대상 | 휘발유·경유·등유의 주별 세전 공급가격 | 동일 | 같음 |
| 국제가격 변수 | 해당 유종의 같은 주·1주 전·2주 전 국제가격 | 동일한 변수 제공 | 같음 |
| 환율 | 별도 변수로 사용하지 않음 | 동일 | 같음 |
| 로컬 자료 범위 | 각 기점 이전까지의 자료 | 같은 구간을 문맥으로 제공 | 범위 같음 |
| 평가 설계 | 정책 이전 자료의 앞 80% 안에서 교차검증 | 동일 | 같음 |
| 예측 시점·길이 | 유종별 22개 기점, 13주 간격, 32주 예측 | 동일 | 같음 |
| 평가 표본·실제값 | 유종별 704개, 전체 2,112개 예측 | 동일 | 같음 |
| 미래 국제가격 | 예측 구간의 실제 국제가격 제공 | 동일 | 같음 |
| 학습 방식 | 기점마다 계수 재추정, 마지막 52주 마진 보정 | 사전학습 가중치 고정, 가격 이력을 입력해 추론 | 다름 |
| 외부 사전학습 | 없음 | 있음; 학습 자료의 기간은 확인 불가 | 다름 |
| 성능 지표 | 공통 평가 코드 사용 | 동일 | 같음 |

자료 처리와 국제가격 시차는 회귀 코드의 함수를 공유한다. 저장된 프로토콜 점검에서 회귀 경로와 딥러닝 평가 경로의 **최근 마진 회귀 MAE**는 세 유종 모두 소수점 네 자리까지 일치했다. 이는 회귀 계산 경로가 일치한다는 의미이며, 두 모델의 성능이 같다는 뜻은 아니다. 별도 회귀 재적합 점검 보고서의 최대 예측 차이도 0.0001원으로 허용 차이 0.01원 이내다.

## 전체 성능 비교

전체 2,112개 예측을 합쳐 계산했다. MAE·RMSE·Bias는 원/리터, MSE는 (원/리터)²이며, 백분율 지표는 %다.

| 지표 | 쉽게 설명하면 | 최근 마진 회귀 | TimesFM 딥러닝 |
| --- | --- | ---: | ---: |
| MAE | 실제 가격에서 평균적으로 얼마나 벗어났는가; 작을수록 좋음 | **19.4050** | 20.6999 |
| MSE | 큰 실수에 더 큰 벌점을 준 평균 제곱오차; 작을수록 좋음 | **660.9014** | 790.2689 |
| RMSE | 큰 실수의 영향을 반영한 오차를 가격 단위로 표시; 작을수록 좋음 | **25.7080** | 28.1117 |
| MAPE | 실제 가격 대비 평균 오차 비율; 작을수록 좋음 | **3.1487%** | 3.3343% |
| sMAPE | 실제값과 예측값을 함께 기준으로 삼은 오차 비율; 작을수록 좋음 | **3.2297%** | 3.4522% |
| WAPE | 절대오차 합을 실제 가격의 절댓값 합으로 나눈 비율; 작을수록 좋음 | **2.6729%** | 2.8512% |
| R² | 실제값 평균만 예측하는 기준 대비 설명력; 클수록 좋음 | **0.9891** | 0.9870 |
| Bias | 평균 예측값 − 실제값; 0에 가까울수록 좋음 | **-4.1284** | -8.0117 |

최근 마진 회귀는 MAE가 **6.26%**, RMSE가 **8.55%** 낮았다. 두 모델 모두 평균적으로 실제 가격보다 낮게 예측했지만, 회귀의 과소예측 정도가 더 작았다. 이는 이번 표본에서 최근 마진 보정이 도움이 됐다는 결과이며, 오차 차이의 원인을 이 표만으로 모두 설명할 수는 없다.

오차 감소율은 아래처럼 계산한다. 분모는 비교 상대인 딥러닝의 오차다.

> 회귀의 오차 감소율 = (딥러닝 오차 − 회귀 오차) ÷ 딥러닝 오차 × 100

## 유종별 비교

각 유종에서 같은 704개 예측을 비교했다.

| 유종 | 회귀 MAE | 딥러닝 MAE | 회귀의 MAE 감소율 | 회귀 RMSE | 딥러닝 RMSE |
| --- | ---: | ---: | ---: | ---: | ---: |
| 휘발유 | 18.0246 | 18.9940 | **5.10%** | 23.2657 | 25.0538 |
| 경유 | 16.9922 | 18.7119 | **9.19%** | 21.6472 | 24.0096 |
| 등유 | 23.1982 | 24.3939 | **4.90%** | 31.1899 | 34.1563 |

세 유종 모두 회귀의 평균 오차가 작았으며, 상대적 차이는 경유에서 가장 컸다. 등유는 두 모델 모두에서 절대 오차가 가장 컸다.

다만 딥러닝의 기점별 MAE가 더 작았던 경우도 휘발유 8/22개, 경유 6/22개, 등유 9/22개 있었다. 특히 등유의 1~4주 평균 MAE는 딥러닝 18.3824원, 회귀 18.5495원으로 딥러닝이 조금 낮았다. 따라서 **전체 평균에서는 회귀가 우세하지만, 시점이나 예측 길이에 따라 결과는 달라진다.**

## 우세가 얼마나 확실한가

기존 교차검증 결과의 통계 검정도 함께 확인했다. 다음은 저장된 Diebold–Mariano 검정값이며 이번 문서 작성 중 새로 검정한 값은 아니다.

| 유종 | 겹치는 기점을 고려한 기존 검정 p값 | 겹치지 않는 기점 8개만 사용한 p값 | 해석 |
| --- | ---: | ---: | --- |
| 휘발유 | 0.4516 | 0.4406 | 회귀의 평균 오차가 작지만 5% 수준에서 유의한 차이로 확인되지 않음 |
| 경유 | 0.0306 | 0.7710 | 전체 기점에서는 회귀 우세가 유의하나, 비중첩 부분집합에서는 확인되지 않음 |
| 등유 | 0.6487 | 0.7513 | 회귀의 평균 오차가 작지만 5% 수준에서 유의한 차이로 확인되지 않음 |

경유 결과는 표본 구성에 민감하다. 비중첩 부분집합은 표본 수가 적어 차이를 발견하기 어려울 수도 있다. 따라서 유의하지 않다는 결과를 ‘두 모델의 성능이 같다’고 해석하지 않는다. 위 값은 여러 유종에 대한 다중검정 보정을 한 값으로 제시하지 않는다.

## 이 결과의 범위

- **미래 국제가격을 알려준 조건부 예측이다.** 실제 미래 국제가격을 모르는 상황의 실전 예측 성능과는 다르다.
- **학습셋 안의 교차검증 결과다.** 별도 뒤 20% 최종 테스트셋이나 정책 이후 성능을 평가한 결과가 아니다.
- **평가 기간이 겹친다.** 32주 예측을 13주 간격으로 수행해 같은 날짜가 서로 다른 기점·리드에서 반복 채점된다. 704개 예측이 독립적인 704주를 뜻하지 않는다.
- **사전학습 이력은 동일하지 않다.** TimesFM의 외부 학습 자료에 평가 기간 정보가 포함됐는지는 저장된 로컬 자료만으로 확인할 수 없다.
- **R²는 정확도 백분율이 아니다.** 전체 R²는 유종·기간 간 가격 수준 차이도 반영하므로, 유종별 오차를 함께 봐야 한다.

## 대회 본문용 정리

> 동일한 자료와 국제가격 입력, 예측 시점 및 평가 기준을 적용한 교차검증에서 최근 마진 회귀 모델의 평균 절대오차는 19.4050원/리터로, TimesFM 딥러닝 모델의 20.6999원/리터보다 약 6.26% 낮았다. 유종별 오차 감소율은 휘발유 5.10%, 경유 9.19%, 등유 4.90%였으며, 전체 RMSE도 약 8.55% 낮았다. 다만 일부 기점과 짧은 예측 구간에서는 딥러닝이 더 우수했고, 통계적 차이도 모든 유종에서 일관되게 확인되지는 않았다. 본 결과는 미래 국제가격이 주어진 조건부 예측이며 두 모델의 사전학습 이력은 동일하지 않다.
