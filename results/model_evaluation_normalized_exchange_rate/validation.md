# 실행 및 검증 기록

- 기존 설치 모델의 가중치로 3개 유종, 22개 기점, 32주 교차검증을 완료했다.
- 모든 모형의 평가 표본·실제값과 기존 평가 격자가 일치함을 실행 과정에서 확인했다.
- 원자료 회귀와 표준화 입력 회귀의 독립 프로토콜 점검은 MAE 차이 표시값 0.0000원으로 통과했다.
- 관련 단위테스트는 1회 실행해 7개 중 6개가 통과했다. 나머지는 표준편차의 약 1e-14 차이를 완전 일치로 비교해 실패했다. 해당 검증을 수치 허용오차 비교로 수정했으며 재실행하지 않았다.
- 최종 테스트셋과 정책 구간은 이번 교차검증에 포함하지 않았다.
