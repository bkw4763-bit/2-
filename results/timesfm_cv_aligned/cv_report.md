# 세전 공급가격 교차검증 보고서 — regression 폴더 기점 이동 백테스트와 동일 격자 (창 겹침, Diebold-Mariano 검정)

## 1. 검증 설계

- 프로토콜: `--protocol regression`. 예측 길이 32주, 기점 간격 13주, 기점 22개.
- 자료·변수·분할: regression 폴더와 동일 (`regression/full_sample/counterfactual.py`). 해당 제품 국제가 시차 3개(같은 주·1주 전·2주 전), 환율 없음.
- 구간: 학습셋만 사용 (2015년01월3주 ~ 2023년12월2주, 462주). 평가셋과 정책 기간(2026-03-13 이후)은 쓰지 않음.
- 첫 기점 문맥 151주, 마지막 기점 문맥 424주.
- TimesFM: 사전학습 가중치 고정, 기점마다 문맥만 확장 (`C:\Users\Admin\Desktop\헤커톤\모델\timesfm-3.0-pytorch`). 회귀 두 모형: 기점마다 비중과 마진을 다시 적합.
- 예측 구간의 **실제** 국제가를 모든 모형에 같이 넣습니다. 즉 국제가가 주어진 조건부 예측이고, 모형 간 입력 정보는 같습니다.
- 창 겹침: 간격 13주 < 예측 32주 → 한 주가 최대 3개 창에 등장.

### 겹침을 감안한 검정

- 기점별 경로 MAE의 차이(모형 − 회귀 최근 마진 (기점별 재적합))에 Diebold-Mariano 검정을 씁니다.
- 분산은 Newey-West HAC(Bartlett 가중, 시차 2)로 보정하고 Harvey-Leybourne-Newbold 소표본 보정을 곱했습니다.
- 추가로 겹치지 않는 기점만 3개마다 골라낸 부분집합에서 쌍체 t도 함께 냈습니다.
- 두 검정 모두 음수면 그 모형이 기준보다 오차가 작다는 뜻이고, p가 작을수록 차이가 뚜렷합니다.

## 7. 해석 시 유의점

- 두 모형은 같은 기점, 같은 주, 같은 국제가 입력으로 채점했습니다. 다른 점은 모형이 자료에서 무엇을 배우는지입니다. 회귀는 비중 3개와 마진 1개를 이 자료에서 추정하고, TimesFM은 외부 사전학습 가중치를 고정한 채 학습셋을 문맥으로만 봅니다.
- TimesFM의 사전학습 자료 기간은 알 수 없습니다. '학습 자료가 기점 이전으로 한정됐다'는 말은 회귀에만 엄격히 성립합니다.
- 기점 22개는 작은 표본입니다. p값은 참고로 보고, 기점별 MAE 표의 패턴과 함께 읽으세요.
