# 주간 정유사 공급가격 TimesFM 실험

## 현재 평가: 매주 확장창·예측 거리별 성능

정책 시행 전 완전 주만 사용해 앞 80%는 개발, 최신 20%는 테스트로 나눈다.
회귀와 TimesFM 모두 매주 기점을 이동하고 그 기점 이전에 관측된 자료를 누적한다.
회귀는 매주 재학습하고 TimesFM은 가중치 갱신 없이 과거 입력 문맥을 확장한다.

1·4·13·26·43주 앞을 각각 예측하고 해당 거리의 마지막 주만 평가한다.
짧은 예측에 그 이후 국제가격이 들어가지 않도록 예측 거리마다 따로 실행한다.
MAE·RMSE·편향은 거리별로 집계하며, 거리를 섞은 전체 MAE는 만들지 않는다.
117주 테스트의 거리별 표본 수는 117·114·105·92·75개이다.
마지막 관측 공급가를 유지하는 무변화 예측도 기준 모형으로 비교한다.

정답은 국내 세전 제품 공급가이며 미래 국제 제품가격의 실제 관측값을 제공한다.
따라서 이 결과는 국제가격이 주어진 조건부 추정이며 원유 자체의 실시간 예측과 구분한다.

결과: `output/expanding_window/validation_predictions.csv`,
`test_predictions.csv`, `model_comparison.csv`, and `locked_settings.json`.
15년 고정 문맥·문맥 후보 선택·비중복 블록·잔여 구간 평가는 현재 실행 경로에서 제거했다.
다른 출력 폴더의 기존 결과는 이전 실험 기록이며 현재 평가에 재사용하지 않는다.

평가 실행: `.\.venv-timesfm\Scripts\python.exe .\딥러닝\compare_timesfm_years.py --evaluation-only`
정책 경로도 갱신하려면 `--evaluation-only`를 생략한다.
루트 파이프라인의 회귀 거리별 지표는 `data/processed/`에 저장한다.
정책 분석 보고서는 `analyze_policy.py --lead 43`으로 거리 하나를 지정해 비교한다.
## 기존 과거 공변량 실험

타겟은 정유사가 주유소·대리점 등에 공급하는 **세전 주간 평균가격(원/L)**이다.
`input/supply_weekly_pretax*.csv`의 실제 주간 값을 사용하고 타겟은 보간하지 않는다.
기존 생성 결과는 삭제했으며, 최신 main의 회귀는 루트 `counterfactual.py`에 있다.

## 전처리

- 공급실적의 일~토 주간을 토요일 날짜로 표시한다. 첫 불완전 주는 제외한다.
- 국제가격·환율은 기존 방식대로 월~금 자료의 결측을 과거 완전 실측 최대 252행,
  최대 5개 이웃의 표준화 거리 역수 가중 KNN으로 보정한다.
- 기존 KNN 거리 특성인 세 유종 주유소 판매가격·국제가격·환율·날짜를 유지한다.
  주유소 판매가격 원자료는 결측 처리에 필요하므로 보존하며 모델 타겟·설명변수에는 넣지 않는다.
- 일별 `국제가격(달러/배럴) × 당일 환율 ÷ 158.987`을 계산하고 일~토 주간 안의
  월~금 5개 값을 평균한다. 국제가격·환율 자체의 주간 평균도 감사용으로 저장한다.
- 모델 입력은 과거 `supply_pretax`, `intl_krw_l`이다. 세전 가격이므로 유류세는 제외한다.
- 초기 과거 이웃이 없는 경우 최초 완전 실측으로 초기화하고 출처를 기록하는 기존 규칙을 유지한다.
- 주간 타겟 결측은 만들거나 보정하지 않는다. 불완전 학습 창은 검증 계획에서 제외한다.
- `imputation_report.csv`에는 집계 전 일간 보정 근거를 저장한다.

## 검증과 예측

| 구간 | 날짜 | 역할 |
|---|---|---|
| 초기 이력 | 2015-01-10~2022-03-12 | 최초 검증에 사용 가능한 과거 |
| 롤링 검증 | 2022-03-13~2024-03-12 | 입력 길이 선택 |
| 최종 보류 테스트 | 2024-03-13~2026-03-12 | 고정 설정 평가 |
| 정책 이후 | 2026-03-13~ | 검증·테스트 제외 |

날짜는 실적 주의 토요일이다. 3월 13일 시행을 포함한 3월 8~14일 주는 정책 구간이다.
1주마다 기준일을 이동하고 이후 4주를 예측한다. 1·2·4주 지점·경로 MAE/RMSE를 저장한다.
입력 후보는 달력 1~15년 중 전체 공통 검증 기간을 확보하는 연수만 사용한다.
설정 선택은 세 유종 동일 가중 4주 경로 MAE이다. 겹치는 예측 창을 독립 표본으로 취급하지 않는다.
TimesFM은 사전학습 가중치를 고정하고 문맥만 갱신한다. 미래 국제가격을 입력하지 않는다.
XGBoost 실행 모델은 아직 연결하지 않았으며 내부 조기 종료 구간은 13주로 바꿨다.

공급실적 주간 가격은 다음 주 금요일에 공개된다. `supply_available_date`에 예정 공개일을 기록한다.
현재 검증은 실적 주 기준 사후 검증으로 공개 지연을 반영한 실시간 백테스트는 아니다.
정책 이후의 미시행 공급가 재귀 예측은 아직 이 CV에 구현하지 않았다.

## 처음부터 실행

```powershell
.\.venv-timesfm\Scripts\python.exe .\딥러닝\prepare_weekly.py
.\.venv-timesfm\Scripts\python.exe .\딥러닝\make_windows.py
.\.venv-timesfm\Scripts\python.exe .\딥러닝\run_baseline.py
.\.venv-timesfm\Scripts\python.exe .\딥러닝\predict_timesfm.py
```

마지막 명령은 전체 주간 검증과 설정 고정을 수행한다. 단일 기준일 실행 확인은
`predict_timesfm.py --mode smoke --years 1`이다. 검증 후 최종 테스트는 `--mode test`로 명시한다.
자료·전처리·주기·타겟이 바뀌면 기존 고정 설정을 재사용할 수 없다.
새 결과는 `output/rolling_cv/<실험ID>/`에 저장한다.
